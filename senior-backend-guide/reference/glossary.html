Glossary

High-frequency nouns from the scenario bank. Search with /.

01  Terms

502 vs 504

502 = bad/empty upstream response; 504 = gateway timed out waiting.

At-least-once

Delivery guarantee that duplicates are possible; pair with idempotent consumers.

Backpressure

Slowing or refusing intake when workers/queues are saturated.

Cache stampede

Many clients miss the same key and stampede the origin; prevent with lock/singleflight.

Circuit breaker

Stop calling a failing dependency temporarily; fail fast and recover half-open.

Cursor pagination

Page using a stable sort key/cursor instead of OFFSET for deep pages.

Exactly-once (practical)

Usually at-least-once transport + idempotent write/dedupe store.

EXPLAIN (ANALYZE)

Postgres plan plus real timings/buffers — use for slow-query debugging.

Hot key

One Redis/Kafka key or partition absorbing disproportionate traffic.

Idempotency key

Client-supplied key so retries of create/pay don’t double-apply.

Load shedding

Dropping or degrading non-critical work to protect the core path.

MVCC

Postgres multi-version concurrency — readers don’t block writers the same way locks do.

Outbox pattern

Write DB state + outbox row atomically; publisher drains outbox to the bus.

Poison message

A message that repeatedly fails; isolate via DLQ so the partition progresses.

Scatter-gather

Sharded query that must hit many shards — latency and cost explode.

Tenant isolation

Hard guarantee one customer cannot read/write another’s data.
