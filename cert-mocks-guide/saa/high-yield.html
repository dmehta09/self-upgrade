SAA-C03 · high-yield Drill before remocks

SAA high-yield drill.

Topics that show up constantly. Use after Mock 1 misses — then remock.

01 Must-drill list

IAM
Role vs user; resource vs identity policy; SCP ceiling; Identity Center federation.
VPC
SG stateful vs NACL; public vs private = routing; gateway vs interface endpoints.
Encryption
KMS CMK vs AWS-managed; Secrets Manager vs SSM Parameter.
HA / DR
Multi-AZ ≠ read replica; RPO/RTO → backup / pilot / warm / active-active.
Storage
S3 classes + lifecycle; EBS vs EFS vs FSx; Intelligent-Tiering default when unsure.
Data
Aurora Multi-AZ; Dynamo on-demand vs provisioned; ElastiCache for hot reads.
Integration
SQS buffer; SNS fan-out; EventBridge rules; ALB L7 vs NLB L4.
Cost
Savings Plans / Spot; NAT cost vs endpoints; Budgets + Cost Explorer.

Deep lessons: aws-saa-guide.
