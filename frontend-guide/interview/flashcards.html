React

0 / 0 known
  • What are the three triggers for a re-render?
    tap to flip
    Its own state changed, its parent re-rendered, or a context it reads changed. Props alone aren’t a separate trigger.
  • Render vs commit — which is expensive?
    tap to flip
    Render = React calling your function (cheap). Commit = mutating the real DOM (the costly part). A no-op render commits nothing.
  • Why does key matter in a list?
    tap to flip
    It gives each item a stable identity so React reorders instead of rebuilding. Index-as-key corrupts state when the list changes order.
  • What does the Rules-of-Hooks “same order” rule protect?
    tap to flip
    Hooks are matched by call order, not name. Conditional hooks shift the order and bind state to the wrong slot — hence no hooks in if/loops.
  • What is useEffect actually for?
    tap to flip
    Synchronizing with systems outside React (subscriptions, non-React widgets). It’s not for deriving state or responding to events.
  • What does the React Compiler (1.0) do?
    tap to flip
    Auto-memoizes components and values at build time. GA since Oct 2025 — manual memo/useMemo/useCallback is now for measured hotspots.
  • How do you write a ref-forwarding component in React 19?
    tap to flip
    Just take ref as a normal prop. forwardRef is no longer needed for new components.
  • What does use() do?
    tap to flip
    Reads a promise (suspends until resolved) or context. Unlike hooks, it can be called conditionally.
  • When does React.memo silently do nothing?
    tap to flip
    When you pass a fresh inline object, array, or arrow function — a new identity each render fails the shallow prop compare.
  • State update batching in React 19?
    tap to flip
    All updates are batched, including inside promises, timeouts, and native handlers (automatic batching). Multiple setState calls = one render.

Next.js / RSC

0 / 0 known
  • Server vs Client Component — the one-line split?
    tap to flip
    Server (default) can fetch/use secrets and ships no JS; Client ("use client") gets state, effects, and events but adds to the bundle.
  • How do you enable Partial Prerendering in Next 16?
    tap to flip
    Set cacheComponents: true in next.config.ts. The old experimental.ppr flag is gone — PPR ships via Cache Components.
  • What’s the caching default in Next 16?
    tap to flip
    Dynamic-by-default. You opt into caching with the "use cache" directive; the compiler derives the cache key.
  • What is a Server Action?
    tap to flip
    A server function ("use server") you call from a form/component to mutate data — no manual API route. Stable in Next 16.
  • updateTag() vs revalidateTag()?
    tap to flip
    updateTag() gives read-your-writes inside a Server Action; revalidateTag(tag, profile) now takes a cache-life profile and invalidates for later requests.
  • What replaced middleware.ts?
    tap to flip
    proxy.ts. Middleware is deprecated; the Edge runtime now lives behind routing/proxy.
  • Which request APIs are async in Next 16?
    tap to flip
    params, searchParams, cookies(), and headers() — you must await them.
  • What bundler does Next 16 use?
    tap to flip
    Turbopack — stable and the default for both next dev and next build (opt out with --webpack).
  • How does a Client Component get server data?
    tap to flip
    A Server Component fetches it and passes it down as props (or as children). Keep the fetch on the server; hand the result across the boundary.

State & data

0 / 0 known
  • staleTime vs gcTime?
    tap to flip
    staleTime = how long data stays fresh (no refetch). gcTime = how long unused data sits in cache before garbage collection (default 5 min).
  • Why isn’t TanStack Query “state management”?
    tap to flip
    It’s a server-state cache — it owns fetching, caching, dedupe, and revalidation. Client/UI state still belongs to React or Zustand.
  • Where should filter/tab/page state live?
    tap to flip
    In the URL (search params). It’s shareable, bookmarkable, and survives refresh — the only source of truth that travels with the link.
  • What is an optimistic update?
    tap to flip
    Show the expected result immediately, then reconcile (or roll back) on the server response. In React, useOptimistic handles the temporary state.
  • Zustand v5: why useShallow?
    tap to flip
    A selector returning a new object/array each call fails reference equality and can cause an infinite re-render loop. useShallow compares shallowly.
  • TanStack Query v5 renames to remember?
    tap to flip
    cacheTime → gcTime; isLoading → isPending. Options take a single object; useSuspenseQuery exists for Suspense.
  • react-hook-form + validation in 2026?
    tap to flip
    RHF (uncontrolled inputs) + zodResolver from @hookform/resolvers + Zod 4. Share the same schema on client and server.
  • When do you reach for Zustand over Context?
    tap to flip
    For frequently-changing global state read by many components. Context re-renders all consumers on change; Zustand lets you subscribe to slices.

Performance

0 / 0 known
  • The three Core Web Vitals + targets?
    tap to flip
    LCP ≤ 2.5 s (loading), INP ≤ 200 ms (responsiveness), CLS ≤ 0.1 (visual stability) — at the 75th percentile of field data.
  • What is hydration, and its cost?
    tap to flip
    Attaching React state + listeners to server HTML. It re-runs component code on the client and ships that JS — the main reason SSR pages can feel slow to react.
  • How does streaming SSR help TTFB/LCP?
    tap to flip
    It flushes the ready HTML immediately and streams slow parts (behind <Suspense>) as they resolve — the shell paints without waiting on the slowest data.
  • What replaced FID, and why?
    tap to flip
    INP. FID measured only the first input’s delay; INP captures responsiveness across all interactions for the whole visit.
  • Biggest lever on bundle size in a Next app?
    tap to flip
    Keep components on the server. Every "use client" boundary plus its imports ships to the browser — push interactivity to the leaves.
  • One concrete fix for poor INP?
    tap to flip
    Break up long tasks: yield to the main thread, defer non-urgent work (transitions), and ship less JS so the handler runs sooner.
  • Common CLS culprit and fix?
    tap to flip
    Images/ads/fonts loading without reserved space. Set explicit width/height (or aspect-ratio) and use font-display fallbacks to stop layout jumps.
  • What ships to the client: CSR vs SSR vs RSC?
    tap to flip
    CSR ships all JS and renders in-browser; SSR ships HTML + all JS to hydrate; RSC ships HTML plus JS only for Client Components.

Styling

0 / 0 known
  • How is config done in Tailwind v4?
    tap to flip
    CSS-first: one @import "tailwindcss"; plus a @theme {} block. tailwind.config.js is legacy (via @config); tokens are real CSS variables.
  • What does cn() do?
    tap to flip
    It’s twMerge(clsx(...)): clsx joins conditional classes, twMerge resolves Tailwind conflicts so the last utility wins.
  • What problem does cva solve?
    tap to flip
    It maps typed props (variant, size) to class strings, so a component exposes a clean variant API instead of ad-hoc conditional class logic.
  • Is shadcn/ui a component library?
    tap to flip
    No — it’s copy-in code you own. npx shadcn@latest add drops Radix-based source into your repo; you edit it directly. No version-locked dependency.
  • How does shadcn handle theming?
    tap to flip
    CSS variables (OKLCH colors). Default style is new-york; components ship data-slot attributes and use ref as a prop (no forwardRef).
  • Why is utility-first CSS fast in production?
    tap to flip
    Classes are reused, so the stylesheet stays small and cacheable; v4’s Oxide engine scans your source and emits only the utilities you use.
  • Container queries in Tailwind v4?
    tap to flip
    Native — mark a parent @container and style children with @sm:/@md: variants based on the container’s width, not the viewport.

Tooling & a11y

0 / 0 known
  • What does “test behavior, not implementation” mean?
    tap to flip
    Assert what the user sees and does (query by role/text, click, expect output) — not internal state or class names. The test survives refactors.
  • What is the testing trophy?
    tap to flip
    Lots of integration/component tests (best ROI), fewer unit and E2E, with static analysis (TS + lint) as the base. Favors confidence per test.
  • Vitest vs Playwright — when each?
    tap to flip
    Vitest + RTL for unit/component logic (jsdom or Browser Mode); Playwright for end-to-end flows in a real browser across multiple pages.
  • ESLint config format in 2026?
    tap to flip
    Flat config (eslint.config.js) is the only format in ESLint 10, paired with typescript-eslint 8. Biome 2 is the fast all-in-one alternative.
  • First rule of accessibility?
    tap to flip
    Use semantic HTML. A real <button>/<nav>/heading gives you focus, keyboard, and roles for free — no ARIA beats wrong ARIA.
  • When is ARIA actually warranted?
    tap to flip
    Only when native HTML can’t express it — custom widgets (tabs, combobox), live regions, dynamic state. Otherwise prefer the element.
  • Why does focus management matter in SPAs?
    tap to flip
    Client navigation doesn’t reset focus like a full page load. Move focus to the new heading/dialog and trap it in modals, or keyboard users get lost.
  • Default bundler for Vite 8?
    tap to flip
    Rolldown (Rust-based) is now the default bundler. Vitest 4 ships stable Browser Mode; pnpm 11 is the common package manager, with bun as the fast challenger.
