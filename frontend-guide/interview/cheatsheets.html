01 One-line glossary

Plain-English definitions for the terms that fly around a frontend loop.

Hydration
React attaching event listeners and state to server-rendered HTML so it becomes interactive.
RSC
React Server Component — runs only on the server, ships zero JS to the browser.
Streaming SSR
Sending HTML in chunks as it’s ready, so the user sees content before everything is done.
PPR
Partial Prerendering — a static shell served instantly with dynamic holes streamed in.
Reconciliation
React diffing the new render output against the previous tree to find minimal DOM changes.
Memoization
Caching a value or component output so equal inputs skip recomputation/re-render.
INP
Interaction to Next Paint — responsiveness metric that replaced FID; target ≤ 200 ms.
Server-state
Data owned by the backend, cached client-side (TanStack Query) — not your app’s own state.
Optimistic update
Showing the expected result immediately, then reconciling when the server responds.
cn()
The shadcn helper twMerge(clsx(...)) — merges class lists and resolves Tailwind conflicts.
cva
class-variance-authority — builds typed variant-to-class maps for component styling.
Server Action
A server function you call from a component/form to mutate data without writing an API route.
