React — the pro mental model

You already ship React. This module rewires the instincts that separate “it works” from “I know exactly why” — rendering, hook identity, effects, composition, and what React 19 now does for you.

00 The one mental model

Your UI is a function of state. You describe what the screen should look like; React figures out how to get there.

Every page here is a corollary of that single idea. You never imperatively poke the DOM — you change state, return JSX, and let React reconcile the difference. Master that and the rest is detail.

Think of it like… analogy

You’re a film director, not a stagehand. You don’t walk on set and move each prop by hand — you describe the scene you want for a given moment, and the crew (React) rearranges the set to match. New state = new scene description; React diffs and moves only what changed.
