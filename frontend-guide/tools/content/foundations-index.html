Foundations — the pro baseline

Before React, two things separate a pro from a tutorial-follower: a typed codebase and a build setup you understand. This module sets that floor — TypeScript that catches bugs at compile time, and the Vite 8 toolchain that makes dev fast and builds lean.

00 Why this comes first

Frameworks change; the floor underneath them doesn’t. Types and tooling are the leverage every other module stands on.

You already write React. What lifts you to senior is shipping code that’s correct before it runs and a build pipeline you can reason about — not just commands you copied. These two pages are short on purpose: get them solid and the rest compounds.

Think of it like… analogy

A pro carpenter doesn’t start by carving wood — they level the floor and sharpen the tools first. TypeScript is the level (everything sits square); Vite is the sharp tool (fast, clean cuts). Skip them and every later cut drifts.
