01 The journey: Junior → Senior

You don’t climb by memorizing more APIs — you climb by understanding what the framework does for you and what it costs. Find your level, then close the gaps. Every chip is one page.

Think of it like… analogy

Line cook → head chef. A junior follows the recipe; a mid knows which technique fits which dish; a senior runs the kitchen — speed, safety, and explaining every choice to the room.

Junior

“I can build it.”

You wire up components, props and useState, fetch in effects, and style with Tailwind.

Close the gaps: why it re-renders, effects as synchronization, and where state should live.

“I can build it right.”

You pick the right rendering strategy, model server vs client state, compose instead of prop-drilling, and test behavior.

Level up with: the server/client boundary, caching, and composition.

02 Where the time goes

Most of modern frontend performance is one story — the path from a request to an interactive page. Keep this picture in your head; every perf topic hangs off one of these boxes.

request → interactive
1 · request

2 · stream
HTML shell
visible fast (LCP)
3 · hydrate
Client JS
attaches handlers
4 · ready
Interactive
responsive (INP)
