Ship it — tooling, a11y & deploy

Your feature works in dev — that’s the start, not the finish. This module covers the last mile: the quality gates, accessibility, and deploy pipeline that turn “works on my machine” into “shipped and trusted by users.”

00 The last mile

Shipping is a pipeline, not a moment. Linting, accessibility, and deploy gates are what stand between code that runs locally and code users can rely on.

A senior engineer is judged less on the first commit than on what surrounds it: consistent code that lints clean, UIs everyone can use, and a deploy flow where broken changes never reach production. These three pages make that last mile boring — in the best way.

Think of it like… analogy

The last mile of a delivery. The package exists the moment it’s built, but it isn’t delivered until it survives quality checks, is reachable by everyone at the door (accessibility), and rides a reliable route to the destination (deploy). Skip the last mile and nothing actually arrives.
