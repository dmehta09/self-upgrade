Styling — Tailwind + shadcn

The modern pro stack is utility-first CSS plus components you own. Tailwind v4 puts styling and design tokens in your CSS; shadcn/ui gives you accessible components copied into your repo — not locked behind a dependency.

00 The idea

Style with utilities, not bespoke CSS files. Build on components you own and can edit, not a black-box library.

Tailwind keeps styling local to the markup, so you read a component and see exactly how it looks. shadcn/ui hands you the source of accessible components — you paste them in, then customize freely. Together they kill both CSS sprawl and library lock-in.

Think of it like… analogy

Tailwind is a labeled drawer of standard parts — you grab p-4 or flex and snap it on, no trip to a separate workshop. shadcn is IKEA furniture: it arrives as parts you assemble and own, so you can saw a leg off if you want — unlike a sealed appliance you can’t open.
