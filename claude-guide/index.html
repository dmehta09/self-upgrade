A visual, beginner-first guide in two tracks. Using Claude teaches how the models think and how to talk to them — prompting, the API, tool use. Claude vs. Claude Code — the one picture to hold

People mix these up constantly. Claude is the brain — a large language model that reads text and predicts a helpful response. Claude Code is the agent that puts the brain to work on your computer: it gathers context, calls the model, runs the tools the model asks for, checks the result, and loops — until the job is done.

The model never touches your files directly. It asks for an action; Claude Code runs it (with your permission) and feeds the result back. That loop is the whole game.
Brain and hands analogy

Think of a brilliant engineer on a phone call. Claude is the engineer — they can reason, but they can't reach into your laptop. Claude Code is the trusted assistant sitting at your keyboard: it describes the screen to the engineer, types what the engineer dictates, runs the tests, and reads the results back. You stay in the room and can say “stop” any time.

What this guide targets as of Jun 2026

A note on fast-moving details

Claude Code ships often and models are added regularly. Exact version numbers and the odd flag will drift — but the workflows (explore→plan→code→commit), the mental models (context, permissions, the agent loop), and the core API shapes are stable. When in doubt, the official docs at code.claude.com/docs and platform.claude.com/docs are the source of truth.
