Agents, MCP & the Agent SDK

You now have every ingredient of an agent: a model, prompts, tool use, and a loop. This lesson zooms out — what makes a good agent, how MCP connects it to the world, and the Claude Agent SDK that hands you the whole machine. It's also the bridge: the SDK is exactly what Claude Code is built on.

01  What an agent is

An agent is an LLM running in a loop with tools: it takes a goal, decides an action, runs it, observes the result, and repeats until done. You saw the bones in Tool use; you saw the polished version in Claude Code's agent loop. Same idea, both times.

02  Anthropic's advice: keep it simple

From Anthropic's Building Effective Agents guidance, the recurring theme is restraint:

Start simple

Many “agents” are a few lines around the API. Reach for one capable agent with good tools before you build a multi-agent system.

Design tools like a human's

Each tool one clear purpose; names and descriptions so obvious that picking the right one is easy. If a person would be confused, so is Claude.

Context engineering > clever prompts

Give the agent the right information at the right altitude. Most agent failures are missing or noisy context, not a weak model.

Keep a human in the loop

Let the agent work autonomously, but gate high-stakes actions. (Exactly what Claude Code's permissions do.)

03  MCP: tools without the glue code

You met MCP in Claude Code — it's a platform standard, not a Claude Code feature. Instead of hand-writing a tool for every external system, you connect an MCP server and your agent gets that system's tools for free. Write the adapter once; every MCP-aware agent can use it. That's how an agent scales from 3 tools to 300 without drowning in integration code.

04  The Claude Agent SDK

Rather than hand-roll the loop, permissions, and context management, use the Claude Agent SDK (Python & TypeScript). It packages everything you've learned — the agent loop, tool use, MCP, subagents, hooks — into a library. It's the same engine that powers Claude Code.

agent.py
pip install claude-agent-sdk

# an agent that can read/edit files and run commands — in a few lines
import anyio
from claude_agent_sdk import query

async def main():
    async for message in query(prompt="Add a /health route and a test, then run the tests"):
        print(message)

anyio.run(main)
It all connects tip

That prompt does what you watched in Your first session — because under the hood, it's the same agent. You've now seen Claude from both ends: the model you call, and the agent built on it.
