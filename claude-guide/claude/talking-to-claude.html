Talking to Claude

There are three front doors to Claude: the chat app for everyday questions, the Console for experimenting and getting API keys, and the API for building it into software. They all speak the same underlying language — a conversation of messages with roles.

02  A conversation is a list of messages

Whichever door you use, a conversation is a sequence of messages, each with a role. There are three:

system
The setup: who Claude should be and the rules to follow (“You are a terse SQL expert. Only return queries.”). Set once; it shapes the whole conversation.
user
You. Your questions and instructions.
assistant
Claude's replies. In a multi-turn chat, past assistant messages are sent back too, so Claude remembers the thread.
A two-turn conversation

role & rules

user

your ask
assistant

Claude replies
For the next turn, you append your new user message and resend the whole list — that's how Claude “remembers.”
The system prompt is a job brief analogy

Before a temp worker starts, you hand them a one-page brief: your role, the house rules, the tone. The system prompt is that brief. The user messages are the tasks you hand over during the shift. Set a good brief and every task goes smoother.

03  The model has no memory between calls

This surprises people: Claude doesn't remember your last conversation. Each request is stateless — the model only knows what's in the messages you send this time. The chat app feels like it remembers because it quietly resends the history every turn. When you build with the API, you manage that history.

This is why context matters everywhere note

“What Claude knows right now = the messages in front of it” is the same truth behind Context is currency in Claude Code. Master prompting next, and you're shaping exactly what's in that window.

Why does the chat app seem to “remember” earlier messages if the model is stateless?
Right. Each call is stateless; the “memory” is the history being resent. When you build with the API, managing that message list is your job — and it's why context discipline matters.
