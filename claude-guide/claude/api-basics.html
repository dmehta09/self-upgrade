Using Claude · lesson 6

The API & SDK

To build Claude into your own software, you call the Messages API — usually through an official SDK. It's the same conversation you met in the chat (system + user + assistant messages), now as a function call. Here's your first call, multi-turn, and streaming — copy and run them.

01  Install & authenticate

Grab an API key from the Console (console.anthropic.com → API keys), set it as an environment variable, and install the SDK.

pip install anthropic
export ANTHROPIC_API_KEY="sk-ant-..."
npm install @anthropic-ai/sdk
export ANTHROPIC_API_KEY="sk-ant-..."
Keep the key secret gotcha

Never hard-code a key or ship it to a browser — anyone with it can spend on your account. Use environment variables (or a secrets manager) on a server you control.

02  Your first call

Three required pieces: a model, a max_tokens ceiling, and a list of messages. The reply comes back in content.

from anthropic import Anthropic

client = Anthropic()  # reads ANTHROPIC_API_KEY

msg = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    system="You are a concise assistant.",
    messages=[{"role": "user", "content": "Give me 3 names for a coffee app."}],
)
print(msg.content[0].text)
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // reads ANTHROPIC_API_KEY

const msg = await client.messages.create({
  model: "claude-sonnet-4-6",
  max_tokens: 1024,
  system: "You are a concise assistant.",
  messages: [{ role: "user", content: "Give me 3 names for a coffee app." }],
});
console.log(msg.content[0].text);

03  Multi-turn: you hold the history

Remember, the model is stateless. To continue a conversation, append Claude's reply and your next message to the list, then call again with the full history.

history = [{"role": "user", "content": "Suggest a name for a coffee app."}]
r1 = client.messages.create(model="claude-sonnet-4-6", max_tokens=512, messages=history)

# append Claude's reply, then your follow-up
history.append({"role": "assistant", "content": r1.content[0].text})
history.append({"role": "user", "content": "Make it more playful."})

r2 = client.messages.create(model="claude-sonnet-4-6", max_tokens=512, messages=history)
print(r2.content[0].text)
const history = [{ role: "user", content: "Suggest a name for a coffee app." }];
const r1 = await client.messages.create({ model: "claude-sonnet-4-6", max_tokens: 512, messages: history });

history.push({ role: "assistant", content: r1.content[0].text });
history.push({ role: "user", content: "Make it more playful." });

const r2 = await client.messages.create({ model: "claude-sonnet-4-6", max_tokens: 512, messages: history });
console.log(r2.content[0].text);

04  Streaming for snappy UIs

For chat interfaces, stream the response so text appears token-by-token instead of after a pause.

with client.messages.stream(
    model="claude-sonnet-4-6", max_tokens=1024,
    messages=[{"role": "user", "content": "Write a haiku about coffee."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
const stream = client.messages.stream({
  model: "claude-sonnet-4-6", max_tokens: 1024,
  messages: [{ role: "user", content: "Write a haiku about coffee." }],
});
for await (const event of stream) {
  if (event.type === "content_block_delta" && event.delta.type === "text_delta")
    process.stdout.write(event.delta.text);
}
SDKs also exist for Java, Go, Ruby, C# & PHP tip

Python and TypeScript are the most popular, but Anthropic ships official SDKs for several languages — same Messages API underneath. Find them on the resources page.

Your API chatbot answers the first question fine but seems to “forget” on the second. Likely cause?
Right. Each call only knows the messages you send. Append the assistant's reply and the new user message to the list, and resend — that's how multi-turn works.
