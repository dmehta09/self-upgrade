MCP servers

MCP — the Model Context Protocol — is an open standard for connecting AI agents to outside systems: GitHub, your database, Sentry, Figma, Slack, anything. An MCP server exposes one of those systems as tools Claude can call. Connect one and Claude Code can use it natively — no copy-pasting, no bespoke integration.

01  Like installing apps

Out of the box, Claude Code can read files and run commands. MCP servers give it new capabilities — query Postgres, open a GitHub PR, read a Sentry issue — each one a small adapter speaking a shared protocol.

Because the protocol is shared, one server works across every MCP-aware tool — write the adapter once, use it everywhere.
MCP is the USB-C of tools analogy

Before USB-C, every device had its own plug. MCP is the universal port: any tool that exposes an MCP server plugs into any agent that speaks MCP. Claude Code is the laptop; servers are the things you plug in.

02  Adding a server

Use claude mcp add with a transport: http for remote servers (most common), stdio for local processes. Then run /mcp to complete any OAuth login.

terminal
# a remote (HTTP) server — e.g. GitHub
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \
  --header "Authorization: Bearer $GITHUB_PAT"

# a local (stdio) server — e.g. a Postgres bridge
claude mcp add --transport stdio db -- npx -y @bytebase/dbhub \
  --dsn "postgresql://user:pass@localhost/app"

# manage them
claude mcp list
> /mcp          # authenticate, view tool counts, toggle servers

03  Scopes & what you can do

local
Just you, just this project (the default).
project
Shared with the team via a checked-in .mcp.json.
user
You, across all your projects.

Once connected, you just ask in plain English and Claude uses the right tools:

  • “Implement the feature in JIRA ENG-4521 and open a PR.”
  • “Check Sentry for new errors on the checkout route since the deploy.”
  • “Find the 10 most recent signups in the database.”
Connect tools you trust gotcha

An MCP server can read data and take actions on your behalf, and a malicious one could misbehave. Add servers from sources you trust, scope them tightly, and review what a project's .mcp.json pulls in before enabling it.

What does adding an MCP server give Claude Code?
Right. MCP is the universal connector. A server exposes a system's capabilities as tools; Claude Code calls them natively, so you can say “open a PR” or “query the DB” and it just works.
