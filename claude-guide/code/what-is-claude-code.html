What is Claude Code?

Claude Code is an agentic coding tool: it reads your codebase, edits files, runs commands, and uses your dev tools — working across many files while you watch, redirect, or step away. It's the model (Claude) wrapped in a body that can actually touch your project.

01  Not a chatbot — an agent

A chatbot answers your question and waits. Claude Code does the work: it explores, plans, edits, runs tests, and reports back. You give it a goal in plain English; it takes real actions to reach it.

A chat assistantClaude Code
You copy code in, paste answers outIt reads and edits the files directly
Has no idea about your projectExplores your repo to understand it
Can't run anythingRuns tests, builds, git — and reads the results
One question, one answerLoops until the goal is met (or it needs you)
A contractor, not an encyclopedia analogy

Asking a chatbot for code is like phoning an expert for advice — you still do the building. Claude Code is more like hiring a contractor who shows up at your house (the repo), looks around, does the work, and shows you what they changed. You're still the one who approves and directs.

02  Five surfaces, one engine

The same Claude Code runs in five places. Your CLAUDE.md, settings, MCP servers, and skills work the same everywhere — pick whichever fits the moment.

Terminal CLI

The most feature-rich surface. Just type claude in any project.

power users

VS Code & JetBrains

A graphical panel in your IDE: inline diffs, plan review, @-mentions.

in-editor

Desktop app

Parallel sessions in isolated worktrees, visual diffs, even computer use.

mac · windows

Web (claude.ai/code)

Run long tasks in the cloud, on repos you don't even have locally.

no setup

Agent SDK

Build your own agents on the same engine, in Python or TypeScript.

programmatic

This guide uses the terminal for examples because it has every feature, but everything transfers. The power-user lesson covers the SDK and parallel surfaces.

03  Install & first run

One command installs it; claude starts it. Native installs auto-update in the background.

terminal
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
#   irm https://claude.ai/install.ps1 | iex

# start it in your project
cd my-project
claude

You'll sign in with a Claude subscription or an Anthropic Console account (API-key billing). The terminal & VS Code also support Amazon Bedrock, Google Vertex AI, and Microsoft Foundry as providers.

First thing to run in a repo tip

Inside a new project, run /init. Claude reads the codebase and writes a starter CLAUDE.md — a short memo it reads every session. More in Project memory.

04  What it's great at

Shipping changes

Features, bug fixes, refactors, tests — the everyday loop of writing and changing code across files.

Understanding code

“How does auth work here?” “Where's rate limiting?” It reads the repo and explains, no edits needed.

Tedious-but-careful work

Migrations, renames, dependency bumps, writing tests — things that are mechanical but easy to get subtly wrong.

Automation & glue

Connect to your tools via MCP, enforce rules with hooks, and run unattended with goals and background sessions.

What's the key difference between Claude Code and a regular chat assistant?
Exactly. Same family of models underneath — the difference is the agency: Claude Code can act on your project and verify its own work, across five surfaces.
