Claude Code · lesson 7

Slash commands

Type / at the start of a message to run a command — a quick action like clearing context, switching models, or kicking off a review. They're the keyboard shortcuts of Claude Code. Type / alone to see every command available to you.

01  The dozen you'll actually use

You don't need to memorize them all. These cover ~90% of day-to-day use:

Manage the session

/clear · /compact · /context · /rewind · /resume — keep the window clean and undo mistakes.

Steer the model

/plan · /model · /effort — choose how it works and how hard it thinks.

Set up the project

/init · /memory · /permissions · /mcp · /agents — configure once, benefit every session.

Ship safely

/code-review · /review · /security-review — check your work before it merges.

03  Custom commands are just skills

Your own commands are now skills. Drop a markdown file in .claude/skills/ (or the older .claude/commands/) and it becomes a /command. The body is the instructions Claude follows; $ARGUMENTS receives whatever you type after the name.

.claude/skills/fix-issue/SKILL.md
---
name: fix-issue
description: Investigate and fix a GitHub issue, then open a PR
---
Fix GitHub issue $ARGUMENTS:
1. `gh issue view $ARGUMENTS` to read it
2. Find the relevant files and understand the bug
3. Implement the fix and add a test
4. Run the tests and linter
5. Commit and open a PR

Now /fix-issue 1234 runs that whole procedure. We go deeper in Skills & plugins.

MCP servers add commands too note

Connected MCP servers can expose their own prompts as commands, shown as /mcp__<server>__<prompt>. More in MCP servers.
