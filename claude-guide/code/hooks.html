Claude Code · lesson 10

Hooks

A hook is a script that runs automatically at a specific moment — before a tool runs, after an edit, when a turn ends. The key difference from CLAUDE.md: a memo is advice Claude usually follows; a hook is code that always runs. When something must happen every single time, you want a hook.

01  Advice vs. guarantee

A sign vs. a turnstile analogy

“Please format your code” is a sign on the wall — usually heeded, sometimes missed. A PostToolUse hook that runs the formatter is a turnstile: every edit goes through it, no exceptions. Use memos for preferences, hooks for must-happens.

02  The events you'll use most

SessionStart
A session begins — inject context, check the environment, warm a cache.
UserPromptSubmit
You hit enter — add context to the prompt or validate it before Claude sees it.
PreToolUse
Before a tool runs — can block it. Veto risky commands or writes to protected paths.
PostToolUse
After a tool succeeds — auto-format, lint, log, or notify.
Stop
Claude tries to end a turn — can block until a check passes. The deterministic verify gate.

There are many more (SubagentStop, PreCompact, SessionEnd, Notification…). Browse them on the cheat sheet.

03  Wiring one up

Hooks live in settings.json under hooks. A matcher selects which tools/events it applies to; the handler is usually a shell command (it also supports http, prompt, and agent handlers).

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      { "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "npx prettier --write $FILE" }] }
    ],
    "PreToolUse": [
      { "matcher": "Bash",
        "hooks": [{ "type": "command", "command": "./.claude/guard.sh" }] }
    ],
    "Stop": [
      { "hooks": [{ "type": "command", "command": "npm test" }] }
    ]
  }
}

Ask Claude to write the hook tip

You rarely hand-write these. Just say: “write a hook that runs eslint --fix after every edit,” or “block any write to the migrations/ folder.” Claude generates the config and the script.

04  Great uses

Auto-format & lint

PostToolUse on edits → run your formatter. Code stays clean without anyone remembering.

Protect paths

PreToolUse that blocks writes to migrations/, infra/, or generated files.

Verify on stop

Stop hook that runs tests and won't let the turn end red — see Closing the loop.

Notify & log

Ping Slack or write an audit line when Claude touches sensitive areas.

You need to guarantee code is formatted after every edit — no exceptions. Best tool?
Right. CLAUDE.md is advice that's usually followed; a hook is code that always runs. “Every single time, no exceptions” is the signature of a hook.
