Glossary

Every term this guide leans on, in one plain-English line. Skim it, or /-search for the one that's tripping you up.

Claude & the models

LLM

Large Language Model — AI trained to predict the next chunk of text, which makes it good at writing, answering, and reasoning.

Claude

Anthropic's family of LLMs (Opus, Sonnet, Haiku), built to be helpful, honest, and harmless.

Token

The chunk an LLM reads and writes — roughly a few characters or part of a word. Cost and context are measured in tokens.

Context window

How much text a model can consider at once. Bigger = more code/docs in view, but a cluttered window still hurts focus.

Prompt

Your instructions to the model. Clearer prompts → better answers.

System prompt

The setup message defining Claude's role, rules, and tone for a whole conversation.

Few-shot

Including a few input→output examples in your prompt to teach the exact format and behavior you want.

Extended thinking

Letting the model reason for longer before answering — big gains on hard, multi-step problems.

Hallucination

When a model states something false as if it's sure. Mitigate with sources, examples, and verification.

Messages API

The core endpoint you call to talk to Claude: a list of role-tagged messages in, a reply out.

Streaming

Receiving the response token-by-token as it's generated, for snappy chat UIs.

Prompt caching

Reusing a long, unchanging prompt prefix across calls to cut cost and latency dramatically.

Tool use

Giving Claude functions it can ask to call (function calling). Claude requests; your code runs them.

Agent

An LLM in a loop with tools: take a goal, decide an action, run it, observe, repeat until done.

Claude Code

Claude Code

Anthropic's agentic coding tool — the agent that reads, edits, and runs your project across five surfaces.

Agent loop

Claude Code's cycle: gather context → act with a tool → verify → repeat.

Plan mode

A read-only mode where Claude explores and proposes a plan you approve before any code is written.

Permission mode

How much Claude asks before acting: default, acceptEdits, plan, auto, or bypassPermissions.

Checkpoint

An automatic savepoint of the conversation and files at each message. Restore with /rewind.

CLAUDE.md

A short memo Claude reads every session — build commands, conventions, constraints. Project memory.

Slash command

A quick action typed with / — like /clear, /plan, /model.

Subagent

A second Claude with its own context that you delegate a task to; it reports back a summary.

Hook

A script that runs automatically at a lifecycle event (e.g. after an edit). Deterministic — it always runs.

Skill

A folder with a SKILL.md teaching Claude a convention or workflow, loaded only when relevant.

Plugin

A bundle of skills, hooks, MCP servers, and commands you install in one step from a marketplace.

MCP

Model Context Protocol — an open standard for connecting agents to external tools and data.

Worktree

An isolated git checkout so multiple Claude sessions can work in parallel without colliding.

Agent SDK

The Python/TypeScript library for building your own agents — the same engine that powers Claude Code.
