Where to go deeper, hand-picked. Start with the official repos and docs — they're authoritative and current. The community lists are great for discovering patterns and extensions once you know the basics.

Official docs & learning

Claude Code docs ↗

The source of truth for everything in Track B — commands, settings, hooks, MCP, the changelog. code.claude.com/docs

Claude API docs ↗

Models, the Messages API, tool use, prompt caching, and the rest of Track A. platform.claude.com/docs

Anthropic Academy ↗

Structured courses and learning paths for building with Claude. anthropic.com/learn

Claude Console ↗

Get API keys, try prompts in the Workbench, and watch usage. console.anthropic.com

Official GitHub repos

anthropics/claude-code ↗

The Claude Code repo — issues, the plugins directory, and the changelog. Your bug-report and example home base.

claude-agent-sdk-python ↗

Build your own agents in Python on the engine behind Claude Code. pip install claude-agent-sdk

claude-agent-sdk-typescript ↗

The same Agent SDK for Node/TypeScript.

anthropic-sdk-python ↗

The official Python SDK for the Messages API (Track A's code). pip install anthropic

anthropic-sdk-typescript ↗

The official TypeScript SDK. npm i @anthropic-ai/sdk

Anthropic Cookbook ↗

Runnable recipes: tool use, vision, RAG, prompt caching, evaluations, and more.

anthropic-quickstarts ↗

Deployable starter apps — customer support agent, financial analyst, computer use.

Prompt engineering tutorial ↗

A 9-chapter hands-on course — the best way to practice Track A's prompting lessons.

anthropics/courses ↗

Anthropic's educational content: API fundamentals, prompt engineering, evaluations.

modelcontextprotocol/servers ↗

Reference MCP servers (filesystem, git, fetch, and more) to connect or learn from.
