Think of building a robot analogy

LangChain is the box of parts (motors, sensors, a brain chip). LangGraph is the wiring diagram that connects them so the robot can decide, act, and react in a loop. LangSmith is the diagnostics laptop you plug in to watch every signal and grade how well the robot did.

Wait — what problem does any of this solve?

A large language model (LLM) like GPT or Claude is brilliant but isolated: it only knows its training data, forgets every conversation, and can't take actions in the real world. To build something genuinely useful — a research assistant, a support agent, a tool that reads your documents — you need to connect the model to data, give it tools, let it remember, and loop until the job is done.

Writing all that plumbing by hand is painful and repetitive. The Lang stack gives you tested, standard pieces for it:

Talk to any model

One interface for OpenAI, Anthropic, Google, local models — swap providers in one line.

Ground it in your data

RAG: load documents, search them by meaning, and feed the relevant bits to the model.

Give it tools & a loop

Let the model call functions, see results, and decide what to do next — that's an agent.

A note on version numbers

These libraries ship often — the exact patch number you install next week will differ. What matters and stays stable: LangChain and LangGraph both reached 1.0 in late 2025, which froze their core APIs. Pin a minor range (e.g. langchain>=1.3,<1.4) and you'll be fine.

PackagePython (PyPI)JS / TS (npm)What it is
langchain1.3.x1.4.xHigh-level building blocks & create_agent
langchain-core1.4.x@langchain/core 1.1.xBase abstractions + the Runnable interface
langgraph1.2.x@langchain/langgraph 1.3.xStateful graph runtime for agents
langsmith0.7.xlangsmith 0.7.xClient SDK for tracing & evaluation

LangSmith itself is a hosted platform (a website), so its "version" is really just the SDK you install. Everything else is an open-source library.
