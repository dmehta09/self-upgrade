Interview gotchas

What mid-senior interviewers probe on LangChain / LangGraph / LangSmith. Plain answers first, then the keywords that signal you ship with current APIs — not 2024 blog posts.

01  What they grade

This round is rarely “write a full agent from scratch.” It is: pick the right layer, name the failure mode, and sound current. Wrong era names (create_react_agent, “LangGraph Platform”) cost trust faster than missing a reducer trivia fact.

layer
SDK call · LCEL chain · create_agent + middleware · custom StateGraph
memory
Checkpointer + thread_id (conversation) vs Store (cross-thread prefs)
HITL
interrupt() re-runs the node — side effects before it are the classic trap
ops
LangSmith traces + evals in CI; deploy name is LangSmith Deployment

02  Highest-frequency questions

Practice answering out loud in under 45 seconds. Open the deep link only if the say-aloud wobbles.

#QuestionSay this (compress)Open
1 LangChain vs LangGraph? LangChain is the high-level API; LangGraph is the stateful runtime. Since 1.0, create_agent compiles to a LangGraph graph — not rivals. Big picture
2 How do you start an agent today? langchain.agents.create_agent + tools. Customize with middleware. Avoid deprecated langgraph.prebuilt.create_react_agent. Middleware
3 When is middleware enough? Cross-cutting: trim history, PII, retries, HITL on tools, model fallback. Escalate to a custom StateGraph when topology changes (branches, fan-out, multi-agent). Why middleware
4 What is LCEL for? Composable runnables with | — prompt | model | parser. Great for straight pipelines; loops/HITL belong in graphs. LC concepts
5 Reducer vs checkpointer? Reducer = how parallel/sequential writes merge inside a run (e.g. append messages). Checkpointer = persist state across invocations via thread_id. Reducers
6 Checkpointer vs Store? Checkpointer is per-thread conversation memory. Store is cross-thread durable facts (user prefs, long-term memory). Memory
7 How does HITL work? interrupt() pauses; resume with Command(resume=…) on the same thread_id. The paused node re-runs from the top. Interrupts
8 HITL footgun? Any side effect before interrupt() re-fires on resume (double email, double charge). Put side effects after the gate or make them idempotent. Interrupts
9 Supervisor vs handoff? Supervisor routes centrally; handoff transfers control to a peer. Pick supervisor for clear ownership, handoff for specialist ping-pong. Architectures
10 What do you deploy on? LangSmith Deployment (Agent Server): assistant → thread → run (+ optional cron). Day-one alternative: FastAPI + Postgres checkpointer. Deployment
11 How do you know it works? LangSmith traces for every run; dataset + evaluators; gate PRs in CI — not vibe checks on one prompt. Evals
12 RAG in this stack? Retrieve → stuff context → generate; production adds hybrid retrieval, rerank, and evals for faithfulness. Framework choice ≠ retrieval quality. RAG

Opening line say it

“I start with create_agent, customize via middleware, drop to a hand-built graph when topology changes, persist with a checkpointer + thread id, and gate quality with LangSmith evals in CI. Deploy name is LangSmith Deployment.”

04  Middleware hooks cheat card

HookUse when
before_modelTrim / summarize messages, dynamic system prompt
wrap_model_callRetry, fallback model, latency budget
after_modelValidate / redact model output
wrap_tool_callTimeouts, tool-error → ToolMessage, audit, HITL on tools

before_* mutates state; wrap_* sits around the call like a decorator. Full table on the middleware page.
