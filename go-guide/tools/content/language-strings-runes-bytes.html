Strings, runes & bytes.

A Go string is an immutable sequence of bytes — UTF-8 encoded text by convention. Indexing gives you a byte; ranging decodes runes. Confusing the two is the classic Unicode bug.

01 Strings are immutable UTF-8 bytes

A string is a read-only slice of bytes (a pointer + length). Source code is UTF-8, so string literals hold UTF-8-encoded text. You cannot mutate a string in place — you build a new one.

In plain English analogy

A string is a printed receipt: a fixed strip of paper with bytes on it. Some characters fit in one slot (ASCII letters), but an emoji or an accented letter is printed across several slots. You can read any slot, but you can't erase one — to "change" the receipt you print a fresh one.

Two key terms. A byte is a uint8 — one slot on the strip. A rune is an int32 holding one Unicode code point — one logical character, which UTF-8 may store in 1–4 bytes.

02 Indexing gives a byte; range decodes runes

s[i] is the i-th byte (a byte), not the i-th character. A for i, r := range s loop decodes UTF-8: i is the byte index where each rune starts, and r is the rune.

03 Conversions & the toolkit

Convert with []byte(s) (the raw UTF-8 bytes), []rune(s) (one element per character), and string(...) back again. []rune is what you want for per-character indexing.

04 The "len is bytes" trap

Gotcha trap

len(s) is the byte length, not the character count, and s[i] is a byte. So reversing a string by bytes corrupts any multibyte character — it splits the UTF-8 sequence into invalid pieces. Reverse over []rune(s) instead, so each character moves as a unit.

The %q on the byte-reversed result shows the é's two bytes (0xC3 0xA9) split to opposite ends — no longer a valid character. The rune version moves é as one unit.

05 Check yourself

For s := "héllo" (the é is 2 UTF-8 bytes), what do len(s) and s[1] give?

Right. len counts bytes: 1+2+1+1+1 = 6. And s[i] indexes bytes, so s[1] is the first of the two bytes encoding é (0xC3 = 195), not a character. For characters, use utf8.RuneCountInString (→ 5) or index []rune(s).
