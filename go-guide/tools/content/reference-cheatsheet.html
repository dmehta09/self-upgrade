01 The language

Declarations, the collection idioms, and the byte/rune/string trio — the bread and butter.

Declarations & zero values

FormMeaning
x := 5Short decl, infers type (functions only).
var x intZero value 0. Package or function scope.
const c = 3Compile-time; untyped constants are flexible.
a, b = b, aMulti-assign & swap, no temp.
Zero values0 · 0.0 · false · "" · nil (ptr/slice/map/chan/func/iface).
_ = f()Blank identifier discards a value.

Slices

IdiomEffect
make([]T, n, cap)len n, capacity cap.
s = append(s, x)Grows; may realloc — reassign the result.
copy(dst, src)Copies min(len) elements; returns count.
s[lo:hi:max]3-index: caps cap at max-lo — stops append clobbering the parent.
s[:0]Truncate, keep backing array (reuse).
s = slices.Delete(s, i, i+1)Remove index i, preserving order.

Maps

IdiomEffect
make(map[K]V)Required before first write — nil-map write panics.
v, ok := m[k]Comma-ok: ok false means absent (not zero).
delete(m, k)No-op if absent; never panics.
for k := range mIteration order is randomized — sort keys to be stable.
map[K]struct{}A set: zero-width value. Add m[k]=struct{}{}.
clear(m)Empties the map in place (1.21).

Strings, runes & bytes

IdiomEffect
len(s)Bytes, not characters.
s[i]The ith byte (uint8).
for i, r := range sDecodes runes; i is the byte offset.
[]rune(s)Per-character slice; len = rune count.
[]byte(s) / string(b)Convert (copies). Mutate via []byte.
utf8.RuneCountInString(s)Count characters without allocating.

02 Errors & concurrency

The two areas interviews probe hardest: idiomatic error handling and the concurrency belt.

Error handling

IdiomEffect
if err != nil { return err }The default. Handle or return — never ignore.
fmt.Errorf("ctx: %w", err)Wrap, preserving the chain (%w, not %v).
errors.Is(err, ErrNotFound)Match a sentinel anywhere in the chain.
errors.As(err, &target)Extract a concrete error type from the chain.
var ErrX = errors.New("x")Declare a sentinel for callers to test.
defer f.Close()Cleanup; runs LIFO. Args evaluated now.

Concurrency cheats

IdiomEffect
go f()Start a goroutine. Returns immediately.
ch <- v / v := <-chSend / receive. Block until the peer is ready (unbuffered).
v, ok := <-chok false & v zero ⇒ channel closed and drained.
close(ch)Only the sender closes, once. Send-on-closed panics.
for v := range chReceive until closed. The clean shutdown signal.
select { case … }Wait on many channels; default = non-blocking.

sync & context

IdiomEffect
wg.Add(1) … go … wg.Done()Wait for N goroutines. Add before the go.
wg.Go(func(){…})Add+go in one call (1.25).
mu.Lock(); defer mu.Unlock()Guard shared state. Never copy a Mutex.
ctx, cancel := WithTimeout(…)defer cancel() — always, even on success.
<-ctx.Done()Cancellation/timeout signal; ctx.Err() says which.
g, ctx := errgroup.WithContext(ctx)g.Go(...); g.Wait() returns the first error.

03 Generics & stdlib one-liners

Type parameters since 1.18, and the batteries that landed in 1.21.

Generics

FormMeaning
func F[T any](x T) TType parameter T; any = no constraint.
[T comparable]Allows == / map keys.
[T cmp.Ordered]Allows < <= > >= (1.21).
[K comparable, V any]Multiple params, e.g. a generic map helper.
type Set[T comparable] map[T]struct{}Generic type. Methods can't add new type params.
interface { ~int | ~string }Union constraint; ~ = underlying type.

slices / maps / cmp

CallEffect
slices.Sort(s)In-place sort of any ordered slice.
slices.SortFunc(s, cmp)Custom comparator returning -1/0/1.
slices.Contains / IndexLinear membership / position.
maps.Keys(m) / maps.Values(m)Iterators over keys/values (1.23 iter.Seq).
cmp.Compare(a, b)-1/0/1 for ordered types.
cmp.Or(a, b)First non-zero argument.

Builtins & misc

CallEffect
min(a, b) / max(a, b)Variadic builtins, any ordered type (1.21).
clear(m) / clear(s)Empty a map / zero a slice (1.21).
len / capLength / capacity of slice/array/chan/map.
new(T)*T pointing at a zero T.
for i := range 5Range over an int, 0..4 (1.22).
for v := range seqRange over an iter.Seq function (1.23).

04 The go command belt

The commands you type every day, plus the flags that matter in interviews and CI.

Build, run & test

shell
go run .            # compile + run this package
go build ./...      # build everything, no output binary kept for ./...
go test ./...       # run every test in the module
go test -run TestX  # run tests matching a regexp
go test -v -cover   # verbose + coverage percentage
go test -bench=. -benchmem  # benchmarks + alloc stats

Correctness & modules

shell
go vet ./...        # catch suspicious code (copied locks, bad Printf)
go test -race ./... # the data-race detector — run in CI
go fmt ./...        # canonical formatting (gofmt)
go mod init mod     # start a module
go mod tidy         # add missing / drop unused deps
go mod download     # fetch deps into the cache
Pro tip interview

If you say one flag in an interview, say -race. "I'd run the test suite under go test -race in CI" signals you respect the memory model. Pair it with go vet for the copied-lock and Printf checks.
