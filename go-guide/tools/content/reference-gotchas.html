Reference

The Go gotchas index.

Every language has a handful of traps that separate "I've written Go" from "I've been bitten by Go." Here they all are in one place — the symptom, the cause, and the one-line fix — each linked to the lesson that explains it. This is the spine of most Go interviews.

01 The catalog

Eighteen traps, grouped by where they live. Click a trap to jump to the lesson that dissects it.

Slices & maps

The trapThe fix
Re-slice aliasing — a sub-slice shares the backing array; writes leak both ways. →copy into a fresh slice when you need independence.
append clobbers a shared slice — append into spare cap overwrites the parent. →Cap the re-slice: s[:n:n] forces a realloc.
range copies the element — mutating the loop value is lost. →Index it: xs[i] = ….
Map iteration order is random — output differs every run. →Collect the keys and sort them.
Writing a nil map panics — reads are fine, writes are not. →make(map[K]V) before the first write.

defer, panic & errors

The trapThe fix
defer piles up in a loop — all defers wait for the function to return. →Put the body in a helper/closure so each runs per iteration.
defer evaluates args now — defer f(x) snapshots x immediately. →Defer a closure: defer func(){ f(x) }().
recover only in a deferred func — called anywhere else it returns nil. →Call recover() inside a deferred function in the same goroutine.

Interfaces & methods

The trapThe fix
nil interface ≠ nil pointer — returning a typed nil makes a non-nil error. →Return a bare nil on success, never a typed nil pointer.
Value vs pointer receiver — a value receiver mutates a copy. →Use a pointer receiver to mutate the original.
Comparing uncomparable types — structs with slice/map/func fields. →Use a comparable key (e.g. a joined string) or reflect.DeepEqual.

Channels

The trapThe fix
Send on a closed channel panics — and closing a closed one panics too. →Only the sole sender closes, exactly once, after all sends.
nil channel blocks forever — send & recv both stall. →Deliberate use: set a channel to nil to disable its select case.

sync & the memory model

The trapThe fix
Unsynchronized shared variable — a write may never be observed. →Establish happens-before: a channel, Mutex, or atomic.
Copied a Mutex / WaitGroup — a copy guards nothing. →Pointer receivers; share the struct by pointer. Heed go vet.
WaitGroup.Add inside the goroutine — races Wait. →Call wg.Add(1) before the go statement.

Loops, context & JSON

The trapThe fix
Loop-variable capture — pre-1.22, closures shared one variable. →Go 1.22 makes it per-iteration; on older, write v := v.
Forgot to call cancel() — leaks the context and its timer. →defer cancel() right after WithTimeout/WithCancel.
JSON: unexported fields / float64 — lowercase fields are skipped; numbers decode as float64. →Export fields, add json tags; expect float64 for untyped numbers.
