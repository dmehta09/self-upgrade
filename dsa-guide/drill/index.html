Timed coding drills.

Reading a pattern and solving under a clock are different skills. Each drill here is a 40-minute coding round: five phases, interviewer-style nudges, a senior grading rubric, and a model answer at the end. Your scores stay on this device.

01  How a 40-minute round runs

Real coding rounds reward pacing as much as cleverness. Candidates who jump straight to code lose points they never knew existed. The drill walks you through the same five phases an interviewer expects, with a per-phase budget that auto-advances when time is up:

PhaseBudgetWhat the interviewer is listening for
Restate & clarify5 minYou restate the problem, ask about edge inputs, and walk one tiny example.
Brute force & Big-O5 minA correct baseline with its exact cost — before any cleverness.
Find the pattern10 minThe pattern named, the example walked through it, target complexity stated.
Code it15 minClean working Python, narrated as you write — not a perfect skeleton.
Test & edge cases5 minA line-by-line trace, the edge cases from phase 1, final complexity.

Work on paper, a whiteboard, or a blank editor — the drill is your interviewer and timekeeper, not your notepad. Hints reveal only if you ask, exactly like nudges in a real round.

The senior bar

Aim for 80%+ on a cold run (no peeking at the lesson the same day). If one phase keeps running over budget, that phase — not the whole problem — is what to practice next.

03  How to self-grade honestly

The rubric only works if you grade what you actually produced, not what you know you could have said. Three rules keep the signal honest:

  • Out loud or on paper counts; in your head doesn't. If you thought "this is a monotonic stack" but never said or wrote it, the line stays unticked — interviewers can't hear thoughts either.
  • Code lines need code. "I'd use a dict and check the complement" doesn't tick a code-phase line; the written if target - x in seen: does.
  • Re-run cold, days later. A score earned right after reading the lesson measures memory; the same score a week later measures skill. The card tracks your best — make the best one a cold one.
Suggested ladder

Warm-ups until all three are 85%+ → Core in any order → Advanced once Core feels boring → Expert last. One drill per sitting beats four in a row; spacing is the point.
