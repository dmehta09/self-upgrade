Python coding round

The problems and Python traps that show up most in mid-senior live coding. Plain answers first, then the keywords interviewers expect. Deep-link into pattern pages and a timed drill when you want the full treatment.

01  What the round grades

In ~40 minutes they watch four things: name the pattern fast, write correct Pythonic code, state time/space, and handle edge cases out loud. Trivia lists matter less than reaching for dict, set, collections, and heapq when they win.

Warm-up arc say it

“Clarify inputs and constraints → brute force for correctness → name the bottleneck → optimal structure → code → complexity → 2–3 edge cases.”

03  Starter solutions (shapes to memorize)

Two Sum

two_sum.py
def two_sum(nums: list[int], target: int) -> list[int]:
    seen: dict[int, int] = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    raise ValueError("no pair")
# Time O(n) · Space O(n)

LRU Cache (OrderedDict)

Acceptable in interviews if you explain eviction. For a from-scratch DLL+dict version, use the Design page.

lru.py
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.od: OrderedDict[int, int] = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.od:
            return -1
        self.od.move_to_end(key)   # mark MRU
        return self.od[key]

    def put(self, key: int, value: int) -> None:
        if key in self.od:
            self.od.move_to_end(key)
        self.od[key] = value
        if len(self.od) > self.cap:
            self.od.popitem(last=False)  # evict LRU

Longest substring without repeating

longest_unique.py
def length_of_longest_substring(s: str) -> int:
    last: dict[str, int] = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best
# Time O(n) · Space O(min(n, alphabet))

04  Python traps that leak into coding

Mutable default
Defaults bind once at def time. Use None and create inside the function.
is vs ==
== is value (__eq__). is is identity — reserve for None / True / False.
Generators
yield pauses; lazy streams beat huge lists. Generator expressions use ().
Decorators
Wrap a callable; use functools.wraps so __name__ / docs survive.
Context managers
with always releases — files, locks. Custom: __enter__/__exit__.
Shallow vs deep copy
copy.copy shares nested objects; copy.deepcopy clones the tree.
GIL
One bytecode thread at a time. CPU-bound → multiprocessing; I/O wait → threads or asyncio.
Reach for stdlib
Counter, defaultdict, deque, heapq, bisect — naming them is a senior signal.
mutable_default.py
# Bad — shared list across calls
def bad(x, acc=[]):
    acc.append(x)
    return acc

# Good
def good(x, acc=None):
    if acc is None:
        acc = []
    acc.append(x)
    return acc

05  Complexity you should say out loud

  • dict / set lookup·insert·delete → amortized O(1)
  • list append → amortized O(1); insert(0) / pop(0) → O(n) — use deque
  • heapq push/pop → O(log n); nlargest(k) → O(n log k)
  • sort → O(n log n) Timsort (stable)

07  Say it out loud

60-second closer say it

“I’d default to hash maps and sliding windows for array/string mediums, heaps for top-k, sort-plus-sweep for intervals, and BFS/DFS on grids. For design, LRU is dict plus doubly linked list — OrderedDict if they accept stdlib. I always state Big-O and avoid mutable defaults.”
