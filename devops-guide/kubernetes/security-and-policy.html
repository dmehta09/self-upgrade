RBAC, NetworkPolicy & PSA.

A cluster without admission and network boundaries is a flat LAN with root-ish pods. Lock identity (RBAC), east-west traffic (NetworkPolicy), and pod privileges (Pod Security Admission) before you scale GitOps.

01 RBAC: who can do what

Role/ClusterRole list allowed API verbs on resources; RoleBinding/ClusterRoleBinding attach them to users, groups, or ServiceAccounts. Prefer namespace Roles; reserve ClusterRoles for platform needs.

ServiceAccount
Identity for pods. Default SA in a namespace is often too broad — create one per app.
Least privilege
Grant get/list/watch on specific resources, not * on *.*.
IRSA / Pod Identity
Maps the SA to a cloud IAM role so the pod never holds long-lived cloud keys (see AWS IAM lesson).
role.yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata: { name: config-reader, namespace: payments }
rules:
  - apiGroups: [""]
    resources: ["configmaps"]
    verbs: ["get", "list"]

02 NetworkPolicy: default-deny east-west

Without a CNI that enforces NetworkPolicy, every pod can talk to every pod. Start default-deny ingress in a namespace, then allow only the paths you need (frontend → API → DB).

In plain English analogy

RBAC is the badge reader on the office door (API access). NetworkPolicy is who can walk the corridors between rooms. PSA is the rule that forbids bringing a blowtorch into the building.

03 Pod Security Admission

PSA labels namespaces with pod-security.kubernetes.io/enforce: restricted|baseline|privileged. Restricted bans hostPath, privileged containers, and running as root — make it the default for app namespaces.

Privileged / hostPath
  • Container breakout → node compromise.
  • Fine for kube-system agents; deadly for random apps.
Restricted
  • Non-root, drop caps, read-only root FS where possible.
  • Pair with resource limits and read-only mounts.
Policy engines P1

Kyverno / Gatekeeper add custom policies (required labels, banned registries) beyond PSA. Mention them in interviews; PSA is the built-in floor.

04 Check yourself

A microservice needs to read one ConfigMap and call the payments API. What is the wrong default?

Right. cluster-admin is the classic interview fail. Scope RBAC, constrain traffic, enforce restricted pods.
