01 Build & ship

The inner loop: Git hygiene, a tiny secure image, and a CI pipeline that keeps main always releasable.

Git essentials

Rebase vs merge
Rebase = linear history, rewrites commits. Merge = preserves both branches with a merge commit.
Undo a commit
git revert (safe, new commit) on shared branches; git reset only on local history.
Trunk-based
Short-lived branches, merge to main daily behind feature flags. The CI-friendly default.
Conventional commits
feat: / fix: / chore: prefixes drive semver + changelogs.

Docker / OCI

VerbDoes
build -tBuild an OCI image (BuildKit, multi-stage).
RUNLayer at build time.
CMD / ENTRYPOINTDefault process at run time.
COPY vs ADDPrefer COPY; ADD also untars/fetches URLs.
Slim it
Multi-stage build, distroless / -slim / Alpine base, USER non-root.
Image vs container
Image = immutable template; container = a running instance of it.

Multi-stage Dockerfile

Dockerfile
FROM python:3.12 AS build
COPY . /src
RUN pip install --target=/out -r /src/requirements.txt

FROM gcr.io/distroless/python3
COPY --from=build /out /app
USER 1000
CMD ["app/main.py"]

CI/CD in one breath

CI
Every change auto-built + tested vs main. Green = mergeable.
Continuous delivery
Every green build is shippable; a human clicks "go."
Continuous deployment
No click — green reaches prod automatically.
Build once
One artifact, tagged by SHA, promoted unchanged through every env.
Auth to AWS
OIDC → assume an IAM role. No long-lived keys in CI.

02 Orchestrate & provision

Kubernetes runs the containers; Terraform provisions the world they run in. Both are declarative — you describe the desired state.

kubectl quick hits

CommandUse
get pods -o wideList pods + node/IP.
describe pod XEvents — why it won't start.
logs -f XTail container logs.
exec -it X -- shShell into a container.
rollout status deploy/XWatch a rollout.
rollout undo deploy/XRoll back to previous ReplicaSet.
apply -f .Reconcile manifests to cluster.

K8s objects, one-liners

Pod
Smallest unit; 1+ containers sharing network + storage.
Deployment
Manages a ReplicaSet for stateless apps; rolling updates + rollback.
StatefulSet
Stable identity + storage per pod (databases).
DaemonSet
One pod per node (agents, log shippers).
Service
Stable virtual IP + DNS load-balancing across pods.
Ingress / Gateway API
L7 HTTP routing into the cluster; Gateway API is the modern successor.
ConfigMap / Secret
Non-secret / secret config injected as env or files.
HPA
Scales replicas on CPU/custom metrics.

K8s anatomy

Control plane
API server, scheduler, controller-manager, etcd (state).
Node
Runs kubelet + container runtime (containerd) + kube-proxy.
Reconcile loop
Controllers drive actual state → desired state, forever.
Probes
liveness restarts a hung pod; readiness gates traffic.

Terraform workflow

terraform.sh
terraform init      # download providers + backend
terraform plan      # diff desired vs current state
terraform apply     # make it so
terraform destroy   # tear it down
State
Maps config → real resources. Store remote (S3 + lock) — never commit it.
Drift
Reality diverged from state (a console click). plan reveals it.
License
Terraform = BSL since 2023; OpenTofu = MPL fork (Linux Foundation).
AWS-native
CloudFormation + CDK (infra in Python/TypeScript).

VPC quick facts

Security group
Stateful, instance-level, allow-only.
NACL
Stateless, subnet-level, allow + deny.
Public vs private
Public subnet routes to IGW; private reaches out via NAT gateway.
Multi-AZ
Spread subnets across AZs for fault tolerance.
EKS identity
IRSA / Pod Identity → pods assume IAM roles, no node-wide keys.

Deploy strategies

StrategyOne-liner
RecreateStop all, start all. Downtime; simplest.
RollingSwap pods a few at a time. No downtime; slow rollback.
Blue-greenTwo full envs; flip traffic. Instant rollback; 2× cost.
CanarySend small % to v2; widen if healthy. Tiny blast radius.
Feature flagShip dark, toggle on per-cohort. Decouples deploy from release.

GitOps in a line

Definition
Git is the source of truth; an agent in-cluster pulls + reconciles to it.
Tools
Argo CD / Flux (sync); Argo Rollouts / Flagger (progressive delivery).
Push vs pull
Pull = cluster syncs itself; no CI creds into prod, auto self-heal.

DORA four keys

MetricMeasures
Deployment frequencyHow often you ship to prod.
Lead time for changesCommit → running in prod.
Change-fail rate% of deploys causing a failure.
Failed-deployment recoveryTime to restore service (MTTR).
Tiers
Elite → High → Medium → Low. First two = throughput; last two = stability.
