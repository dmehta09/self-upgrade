Reference · glossary

DevOps glossary, A–Z.

One crisp line per term — the vocabulary an interviewer expects you to use precisely. AWS-first, June 2026. For deep telemetry terms, pointers lead to the companion Observability guide.

01 A – F

Artifact
The immutable build output (a container image or package), versioned and promoted unchanged across environments.
Auto Scaling Group (ASG)
AWS construct that keeps a target number of healthy EC2 instances and scales them in/out across AZs.
Blue-green
Deploy strategy running two full environments and flipping all traffic at once; rollback is instant, cost is doubled.
Canary
Deploy strategy that routes a small % of traffic to the new version and widens only if metrics stay healthy.
cgroups
Linux kernel feature limiting a process group's CPU, memory, and I/O — the resource fence behind containers.
CI/CD
Continuous integration (auto build + test every change) plus continuous delivery/deployment (auto-ready or auto-shipped releases).
Container
An isolated process using the host kernel with its own filesystem, network, and resource limits (namespaces + cgroups).
containerd
The CNCF container runtime Kubernetes uses by default; the old Docker shim (dockershim) is long removed.
Control plane
Kubernetes' brain: API server, scheduler, controller-manager, and etcd that drive desired state.
DaemonSet
Kubernetes object that runs exactly one pod on every (matching) node — used for agents and log shippers.
Declarative
You describe the desired end state and the system reconciles to it, rather than scripting each step (imperative).
DevSecOps
Building security into the pipeline and dev loop ("shift-left") rather than bolting it on before release.
DORA
Four delivery metrics — deploy frequency, lead time, change-fail rate, and failed-deployment recovery time (MTTR).
Drift
When real infrastructure diverges from its IaC state, usually via a manual change; terraform plan reveals it.
ECR
Elastic Container Registry — AWS's private OCI image registry that EKS/ECS pull from.
ECS
Elastic Container Service — AWS's native container orchestrator; pairs with Fargate for serverless compute.
EKS
Elastic Kubernetes Service — AWS's managed Kubernetes control plane.
etcd
The distributed key-value store holding all Kubernetes cluster state; the single source of truth behind the API server.
Fargate
AWS serverless compute for containers (ECS/EKS) — you run tasks without managing EC2 nodes.
Feature flag
A runtime toggle that decouples deploy from release, enabling dark launches, gradual rollout, and instant kill-switches.

02 G – N

GitOps
Operating model where Git is the source of truth and an in-cluster agent (Argo CD, Flux) pulls and reconciles the cluster to it.
Graviton
AWS's ARM-based CPUs offering better price/performance than comparable x86 instances.
HCL
HashiCorp Configuration Language — the declarative syntax used to write Terraform/OpenTofu.
Helm
Kubernetes package manager; bundles manifests into versioned, parameterized "charts."
Horizontal Pod Autoscaler (HPA)
Kubernetes controller that scales a workload's replica count up/down on CPU or custom metrics.
IaC (Infrastructure as Code)
Defining infrastructure in version-controlled, declarative files so it's reproducible, reviewable, and automated.
IAM role
An AWS identity with policies that entities assume to get temporary, scoped credentials — no static keys.
Idempotent
An operation that yields the same end state no matter how many times it runs — core to safe IaC and config management.
Immutable infrastructure
Servers/images are never patched in place; you replace them with a new version and discard the old.
Ingress
Kubernetes object for L7 HTTP routing into the cluster; the role-oriented Gateway API is its modern successor.
kubectl
The Kubernetes CLI used to apply manifests and inspect/operate cluster objects.
kubelet
The agent on every node that starts pods and reports their health to the control plane.
Kubernetes
The container orchestrator that schedules, scales, and self-heals workloads via a declarative reconcile loop.
Least privilege
Granting only the permissions a workload or person needs, nothing more — the default security posture.
Multi-AZ
Spreading resources across Availability Zones so the loss of one zone doesn't take the service down.
NACL
Network ACL — a stateless, subnet-level firewall in a VPC that supports both allow and deny rules.
NAT gateway
Lets instances in a private subnet reach the internet outbound without being publicly reachable inbound.

03 O – Z

OCI
Open Container Initiative — the standard image and runtime format, so images run across any compliant tool/registry.
OIDC
OpenID Connect — federated identity that lets CI assume an IAM role with short-lived tokens instead of stored keys.
OpenTofu
The MPL-licensed, Linux Foundation fork of Terraform created after its 2023 move to the BSL license.
Pod
Kubernetes' smallest deployable unit: one or more containers sharing a network namespace and storage.
Postmortem (blameless)
An incident review that targets systemic causes, not individuals, so facts surface freely and action items result.
RBAC
Role-Based Access Control — granting permissions via roles bound to users/service accounts (in Kubernetes and beyond).
Reconciliation
The continuous loop where controllers drive actual state toward declared desired state — the heart of Kubernetes and GitOps.
Registry
A store for versioned container images (ECR, GHCR, Docker Hub) that orchestrators pull from.
Rollback
Reverting to a previously known-good version after a bad deploy — the speed of this drives MTTR.
Rolling update
Replacing instances/pods a few at a time so there's no downtime; rollback is gradual, not instant.
RPO (Recovery Point Objective)
The maximum acceptable data loss, measured in time — drives backup/replication frequency.
RTO (Recovery Time Objective)
The maximum acceptable time to restore service after an incident — drives failover design.
Runbook
A documented, step-by-step procedure for handling a known operational task or incident.
SBOM
Software Bill of Materials (SPDX/CycloneDX) — an inventory of every component in a build, key to fast vulnerability triage.
Security group
A stateful, instance-level VPC firewall with allow-only rules; return traffic is automatically permitted.
Service (K8s)
A stable virtual IP + DNS name that load-balances traffic across a label-matched set of pods.
Service mesh
An infrastructure layer (Istio, Linkerd) adding mTLS, traffic shifting, and retries to service-to-service traffic.
Sidecar
A helper container running alongside the main one in a pod (proxy, agent); now a stable Kubernetes container type.
SLO
Service Level Objective — a target for reliability you commit to. The math, SLIs, and error-budget alerting live in the companion Observability guide.
Terraform
HashiCorp's IaC tool using HCL with a plan/apply workflow and state; BSL-licensed since 2023.
Trunk-based development
Branching model where everyone integrates small changes to main frequently — the CI-friendly default.
VPC
Virtual Private Cloud — your isolated AWS network of subnets, route tables, gateways, and firewalls.
