Coding–decoding.

A word is scrambled by a secret rule — your job is to crack the rule from one example, then apply it. Once you see the shift, the rest is bookkeeping.

01 The idea

Coding hides a letter ↔ letter rule. Compare each letter of the code with its original, measure the shift, and reuse it. Keep the alphabet positions handy: A=1 … Z=26.

Almost every variant is one of five: shift by n (Caesar), positional value, letter substitution, symbol coding, or number coding. Identify which, and the decode is mechanical.

In plain English analogy

It's a secret-decoder ring. Slide every letter forward the same number of steps and the message turns to gibberish; slide it back and it returns. You just need to find how many steps the ring was turned — from one matched pair.

02 Letter shift (Caesar): +n with wraparound

Pick one letter and its code, count the gap — that's n. Apply the same +n to every letter, and when you run off the end, wrap Z → A (Y+3 = B, not "}"). Treat the alphabet as a loop, not a line.

Shift +3 — every letter slides three steps right
A→D, B→E, C→F: a clean +3. Past the end the strip loops, so Y→B and Z→C — wrap, don't fall off.
Common trap gotcha

Two errors sink most people: off-by-one on the shift (count the jumps, not the letters — A to D is +3) and forgetting to wrap Z → A. Also, don't confuse a shift (CAT → DBU) with a reversal (cat → tac): a shift changes the letters, a reversal only flips their order.

03 Positional value & substitution

Many codes just swap each letter for its position number (A=1, B=2, … Z=26) or for another fixed letter/symbol. Spot whether the code is letters, numbers, or symbols, and decode one column at a time.

A=1 · B=2 · C=3 · … · M=13 · N=14 · … · Z=26 # memorise the anchors: E=5, J=10, O=15, T=20, Z=26
Slow way

Recite "A, B, C…" up to the letter every single time you need its number. Burns seconds and invites miscounts.

Fast way

Anchor on the 5s — E=5, J=10, O=15, T=20, Z=26 — then nudge. Q is "just past O(15)" = 17. Instant.

If CAT is coded DBU (each letter +1), what is the code for DOG?

EPH. The rule from CAT→DBU is +1 on every letter. Apply it uniformly: D→E, O→P, G→H. The traps shift only some letters.

04 Solve it fast

Shift +2: the letter M becomes?warm-up
Solve it

M is the 13th letter; +2 lands on the 15th = O. (M → N → O, two steps.)

The fast way shortcut

Count jumps on your fingers — M, then two hops: N, O. For small shifts you never need positions at all.

With A=1 … Z=26, what is the code for BEAD?stretch
Solve it

B=2, E=5, A=1, D=4 → 2 5 1 4. Just read each letter's position straight off.

The fast way shortcut

Anchor on E=5: B is two before (2), A is one before that (1), D is one before E (4). No full recital needed.

If "cat" → "tac" (reverse), then "dog" → ?core
Solve it

The rule isn't a shift — the letters are unchanged, only the order flips. d-o-g reversed is god.

The fast way shortcut

First check: did the letters change or just move? Same letters, new order = reversal. Don't waste time computing a shift that isn't there.
