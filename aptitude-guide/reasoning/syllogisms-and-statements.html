Logical Reasoning · syllogisms

Syllogisms & statements.

You're handed statements and a list of conclusions — tick only what must follow. Draw the circles, ignore the real world, and these become reliable marks.

01 The idea

A syllogism gives you statements (treated as true) and asks which conclusions are forced. Draw each as overlapping circles (a Venn diagram) and read off only what every valid picture shares.

The skill isn't logic theory — it's translating "All / Some / No" into circles, then refusing to tick anything the picture doesn't guarantee.

In plain English analogy

Think of nested boxes. "All cats are animals" puts the cat-box inside the animal-box. Once it's drawn, you just look: anything in the cat-box is unavoidably in the animal-box. The diagram, not your opinion, decides what's true.

02 Turn each statement into circles

Four statement types, four pictures. All A are B → A sits inside B. No A are B → two separate circles. Some A are B → circles overlap. Some A are not B → part of A sticks out of B.

All A are B (nested) vs Some A are B (overlap)
"All A are B" buries A inside B; "Some A are B" only forces the overlapping sliver to exist.
Pro tip tip

"Some A are B" also means "Some B are A" — overlap works both ways. And "All A are B" never tells you anything about B alone; B can be far bigger than A.

03 "Definitely true" vs "possibly true"

A conclusion is valid only if it holds in every diagram you can legally draw. If you can sketch even one valid arrangement where it fails, it is not a must — reject it, however likely it feels.

Definitely true

Holds in all legal pictures. Example: All A are B, all B are C → All A are C. No way to draw it otherwise.

Only possibly true

Holds in some picture but not all. Some A are B → "Some A are not B" is merely possible — A could sit entirely inside B.

Common trap gotcha

"Some A are B" does not guarantee "Some A are not B" — all of A might fit inside B. And never import real-world knowledge: if a statement says "All birds are fish", you accept it for the puzzle and reason from the statements only.

Statements: All squares are rectangles. Some rectangles are blue. Can you conclude "Some squares are blue"?

No. Draw the squares inside the rectangle circle, then put the blue patch on the rectangle part that excludes squares — a legal picture with zero blue squares. No forced link, so reject it.

04 Statement–conclusion & statement–assumption

Same rule, two close cousins. Conclusion: does it necessarily follow from the statement? Assumption: is it something the speaker must already be taking for granted for the statement to make sense?

Conclusion
Accept only if it is forced by the statement. A merely reasonable add-on fails.
Assumption
The unstated thing required for the statement to hold. Test it with negation: if denying it breaks the statement, it's a genuine assumption.
Reject
Anything extreme, outside knowledge, or only "probably" true — same discipline as the Venn rule.
Pro tip tip

Assumptions are almost always implicit. If a fact is already stated in the passage, it is not an assumption — assumptions are the silent things the statement leans on.

05 Solve it fast

All cats are animals. All animals are mortal. Therefore?warm-up
Solve it

Nest the circles: cats ⊂ animals ⊂ mortal. Anything in the innermost circle is in the outermost, so All cats are mortal.

The fast way shortcut

Two "All" statements chain transitively: All X are Y, all Y are Z → All X are Z. No diagram needed once you spot the chain.

Some pens are red. All red things are bright. Valid conclusion?core
Solve it

The red pens exist (overlap of pens and red). All red things are bright, so those red pens are bright → Some pens are bright.

The fast way shortcut

"Some X are Y" + "All Y are Z" pushes the overlap into Z → "Some X are Z". Don't over-reach to "All pens are bright" — only the red ones are covered.

All A are B. No B are C. Therefore?stretch
Solve it

A is buried inside B, and B shares nothing with C. So A — being part of B — also touches nothing in C: No A are C.

The fast way shortcut

If A lives entirely inside B, A inherits B's separations: B ∩ C = ∅ forces A ∩ C = ∅. "All … inside, No … apart" → "No A are C".
