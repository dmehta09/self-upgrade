Reference · glossary

Glossary.

The aptitude & reasoning vocabulary, A–Z — the terms that show up in question stems and instructions.

01 A–Z

Alligation
A shortcut for mixtures and weighted averages: the ratio of two ingredients equals the cross-differences of their values from the mean — cheaper : dearer = (dearer − mean) : (mean − cheaper).
Analogy
A "A : B :: C : ?" question — identify the relationship between the first pair and apply the same to the second.
Approximation
Rounding numbers to estimate an answer quickly; common in data interpretation where exact arithmetic wastes time.
Average speed
Total distance ÷ total time — for two equal legs at speeds x and y it is the harmonic mean 2xy/(x+y), not (x+y)/2.
Caselet
A data-interpretation set where the data is given as a paragraph of prose rather than a chart; extract it into a table first.
Compound interest (CI)
Interest on principal plus accumulated interest: amount = P(1 + R/100)ⁿ.
Cyclicity
The repeating pattern of unit digits of powers (e.g. 7 → 7, 9, 3, 1 every four powers); used to find a last digit.
Data sufficiency (DS)
A format asking whether the given statements are enough to answer — not what the answer is.
Discount
A reduction on the marked price (not the cost price): selling price = marked price × (1 − discount%).
HCF
Highest Common Factor — the largest number dividing all given numbers. HCF × LCM = product of the two numbers.
LCM
Lowest Common Multiple — the smallest number all given numbers divide into; the backbone of the time-and-work shortcut.
Marked price (MP)
The listed/tag price before any discount.
Odd days
In calendar problems, the remainder when a number of days is divided by 7 — it tells you how the weekday shifts.
Para-jumble
A set of shuffled sentences to reorder into a coherent paragraph; find the opening sentence, then follow pronoun and transition chains.
Permutation / Combination
Permutation (nPr) counts arrangements where order matters; combination (nCr) counts selections where it doesn't.
Pythagorean triple
Whole-number right-triangle sides such as 3-4-5, 5-12-13, 8-15-17 — recognising them skips the square root in direction problems.
Ratio
A comparison a : b of quantities; "parts" thinking (total = a + b parts) divides amounts quickly.
Relative speed
Speed of one body as seen from another: add speeds when moving toward each other, subtract when moving the same way.
Simple interest (SI)
Interest only on the principal: SI = P·R·T / 100.
Syllogism
A deduction from "All / Some / No" statements; solve with overlapping Venn circles and accept only conclusions that must follow.
Unit digit
The last digit of a number; found for powers using cyclicity.
Venn diagram
Overlapping circles showing how sets relate; used for syllogisms and for set-based data interpretation.
