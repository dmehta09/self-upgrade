Model development · evaluate & Clarify

Pick the metric that matches the mistake cost.

MLA-C02 ties problem type to metrics — accuracy alone is rarely right. SageMaker Clarify adds bias and explainability when stems mention fairness, regulators, or “why was this denied?”

01 Metrics by problem type

Classification with class imbalance → precision/recall/F1, PR-AUC, or cost-weighted metrics — not raw accuracy. Regression → RMSE/MAE. Ranking → MAP/NDCG. Multiclass → macro vs weighted F1 depending on whether rare classes matter equally.

Imbalanced fraudPrecision at fixed recall, PR-AUCLedger Bank: false alerts anger merchants
Medical screeningRecall (sensitivity) at acceptable FP rateAcme Health: missing readmission is costly
Regression forecastRMSE if large errors hurt moreBed occupancy prediction

02 SageMaker Clarify: bias & explainability

Run Clarify on training data or endpoint predictions for pre-training bias, post-training bias, and SHAP feature importance. Use when stems cite protected attributes, disparate impact, or explainability to clinicians/customers.

Pre-training bias
Class imbalance or label bias before model exists — e.g. historical denial rates by zip code.
Post-training bias
Compare metrics across facets (gender, age band) on holdout or live shadow traffic.
Explainability
SHAP values for tabular models — which features pushed this patient’s score up.
Acme Health
Clarify facet on age/sex for readmission model before hospital board review.
Ledger Bank
SHAP on fraud decline to satisfy “reason code” regulations without exposing full model weights.
Common trap gotcha

Accuracy on 99% legitimate transactions. A dumb “never fraud” model scores 99% accuracy but catches zero fraud — exam stems with imbalance want precision/recall trade-offs, not accuracy.

03 Holdout vs cross-validation

Holdout test set — untouched until final sign-off; reports production-realistic performance. Cross-validation — for model selection and HPO on limited data. Exam rule: tune on train/val (or CV folds), report once on holdout.

Team used the test set to pick hyperparameters, then quoted test AUC in the board deck. What went wrong?

Right. Holdout is for final evaluation only. Tuning belongs on validation or CV; training accuracy is in-sample and useless for generalization claims.

04 Exam rapid-fire

Fraud detection metric — accuracy or something else?core
Model answer

Precision/recall trade-off, PR-AUC, or precision at a fixed recall — because negatives dominate and false positives have operational cost.

Say it out loud say it

"Imbalanced classification → PR-AUC or precision/recall, never headline accuracy."

When do you reach for Clarify?warm-up
Model answer

Bias across facets (pre/post training) or local/global explainability (SHAP) — especially regulated or customer-facing denial decisions.

Say it out loud say it

"Fairness facets or SHAP why → SageMaker Clarify."

Holdout vs k-fold — exam one-liner?stretch
Model answer

K-fold for model selection on small data; single holdout for unbiased final metric after all tuning stops.

Say it out loud say it

"CV to choose; holdout to report — never tune on holdout."
