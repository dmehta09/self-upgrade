# Prompt contract — AWS MLA Field Guide

When extending this guide:

1. Stay inside `aws-mla-guide/`. No cross-guide links or pasted prose from other guides.
2. Target **MLA-C02** (data prep 28%, model/FM 24%, deploy 24%, operate 24%). Mention C01 only as retirement context on exam-method.
3. Write for readers with **basic ML**; teach AWS services as **exam choosers**.
4. Prefer decision Mermaids, versus cards, and 2–3 named stories (Acme Health, Ledger Bank).
5. Mock questions need `domain`, `stem`, `choices`, `answer`, `why`, and `lesson` (lesson id from manifest).
6. Run `./bin/guide build aws-mla-guide` and `./bin/guide verify aws-mla-guide` before claiming done.
