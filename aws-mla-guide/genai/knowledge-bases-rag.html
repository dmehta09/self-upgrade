GenAI · Knowledge Bases & RAG

Design RAG that survives the exam.

Bedrock Knowledge Bases ingest S3 (and connectors), chunk, embed, and retrieve at query time. MLA stems test chunking, metadata filters, vector store choice, and when hybrid search beats pure vectors.

01 Knowledge Base RAG path

Documents → chunk → embed → vector store → at query time retrieve top-k → FM generates grounded answer. Bedrock manages sync, embedding model, and Retrieve API for custom orchestration.

02 Chunking, metadata & vector store

Chunk size — smaller for precise FAQ; larger for narrative policy sections. Use metadata filters (department, doc version, effective date) so nurses only see Acme formulary, not research drafts. Vector store — OpenSearch Serverless, Aurora pgvector, Pinecone, etc.; pick managed + ops fit; exam often accepts “Bedrock-managed OpenSearch” for least ops.

Hybrid search
Keyword + semantic — wins when stems mention exact SKU codes, ICD-10 codes, or legal citation numbers vectors miss alone.
Acme Health
Metadata department=nursing, status=approved on formulary chunks; nightly S3 sync.
Ledger Bank
Hybrid for loan product IDs in memos; filter by region=EMEA for GDPR residency splits.
Chunk overlap
Prevents sentences split across boundaries from losing context — tune when answers truncate mid-clause.
Common trap gotcha

Giant chunks “for more context.” Huge chunks dilute retrieval — the FM gets irrelevant paragraphs and hallucinates bridges. Match chunk size to retrieval precision the stem asks for.

03 Exam quiz

Users must only query approved 2026 policies, not archived drafts in the same bucket. Best KB feature?

Right. Metadata filters scope retrieval. Manual deletes are fragile; FMs don’t reliably ignore bad chunks in context.

04 Exam rapid-fire

When hybrid search over pure vector?core
Model answer

When queries include exact identifiers, SKUs, legal cites, or rare tokens semantic search alone misses — combine keyword BM25 with embeddings.

Say it out loud say it

"Exact codes or IDs in the question → hybrid search, not vectors alone."

What does Bedrock KB sync do?warm-up
Model answer

Ingests new/changed S3 objects, chunks, embeds, and updates the vector index so RAG reflects fresh documents without manual re-embedding scripts.

Say it out loud say it

"KB sync keeps the index aligned with S3 — chunk, embed, index automatically."

Vector store chooser — exam heuristic?stretch
Model answer

Pick a store Bedrock Knowledge Bases supports in your Region; prefer managed OpenSearch Serverless or Aurora pgvector when stem wants least ops and existing AWS footprint.

Say it out loud say it

"Supported + managed + matches existing DB/search stack — don't roll DIY FAISS on EC2 for MLA stems."
