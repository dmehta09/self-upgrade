Exam prep · MLA-C02 domains

Four domains. One ML engineering brain.

MLA-C02 scores you on Data preparation · Model/FM development · Deploy & orchestrate · Operate, monitor, secure. This map shows which guide lessons feed each domain — study by domain when a mock exposes a weak area. As of September 2026.

01 Official domains at a glance

DomainWeight (approx.)What "good" looks like
1 · Data preparation for ML~28%Ingest, transform, feature engineering, Feature Store, embeddings for RAG, integrity/bias/leakage
2 · ML model & FM development~24%Algorithm choice, SageMaker training, HPO, evaluation, Clarify, JumpStart, Bedrock FM selection
3 · Deployment & orchestration~24%Inference modes, Registry, Pipelines/CI/CD, Agents, Step Functions, RAG deploy patterns
4 · ML solution monitoring & security~24%Model Monitor, drift, IAM roles, KMS, cost/accelerators, lineage, Guardrails

Weights shift slightly over time — confirm against the current AWS exam guide. Tag every practice question: Data, Model, Deploy, or Operate.

04 Quick self-check

Stem: "training and inference features must match; low-latency serving." Domain?warm-up
Answer

Data (Domain 1) — Feature Store online/offline consistency. Deploy appears only if stem asks endpoint type.

Stem: "only approved models reach production endpoint." Domain?core
Answer

Deploy (Domain 3) — Model Registry approval + pipeline gate.

Stem: "feature distribution shifted; automate retrain." Domain?core
Answer

Operate (Domain 4) — Model Monitor + EventBridge, often crossing into Deploy for pipeline.
