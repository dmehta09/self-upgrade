# AWS MLA Field Guide

Offline exam guide for **AWS Machine Learning Engineer Associate (MLA-C02)** — classic MLOps plus Bedrock, RAG, agents, and responsible GenAI.

Open [`index.html`](./index.html) in a browser (or via the hub). Build/verify:

```bash
./bin/guide build aws-mla-guide
./bin/guide verify aws-mla-guide
```

See [`tools/AUTHORING.md`](./tools/AUTHORING.md) for content rules. Fully self-contained — no dependency on other field guides.
