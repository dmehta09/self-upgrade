Reference · glossary

MLA glossary, A–Z.

Crisp definitions for Machine Learning Engineer – Associate vocabulary. AWS-first, September 2026. Self-contained for this guide — Acme Health & Ledger Bank contexts where helpful.

01 A – F

Action group (Bedrock)
OpenAPI-defined tools an Agent can invoke via Lambda — e.g. Ledger leave-balance API.
Async inference
SageMaker pattern for large payloads: input to S3, process asynchronously, notify via SNS or poll.
Automatic Model Tuning (AMT)
SageMaker hyperparameter optimization running multiple training trials against an objective metric.
Baseline (Model Monitor)
Reference statistics from training data used to detect drift in live endpoint traffic.
Batch Transform
Offline SageMaker inference job reading/writing S3 — no persistent endpoint.
Bedrock
Managed foundation model service: InvokeModel, Knowledge Bases, Agents, Guardrails, fine-tuning.
Clarify (SageMaker)
Bias detection and SHAP explainability for datasets and models pre/post training.
ConditionStep
SageMaker Pipelines branch on metric comparisons before register/deploy steps.
Data capture
Endpoint logging of request/response samples to S3 for monitoring and audit.
Data drift
Change in live feature distributions versus training baseline — detected by Model Monitor.
Embedding
Dense vector representation of text/images for similarity search in RAG pipelines.
Execution role
IAM role assumed by SageMaker jobs/endpoints for temporary AWS API access.
Feature Store
SageMaker managed store with offline (training) and online (inference) feature serving.
Foundation model (FM)
Large pre-trained model (LLM, multimodal) accessed via Bedrock or SageMaker JumpStart.

02 G – M

Guardrails (Bedrock)
Policy layer filtering unsafe content, denied topics, and PII in GenAI requests/responses.
Hyperparameter optimization (HPO)
Automated search over training hyperparameters — SageMaker AMT.
Inferentia
AWS inference chip (Inf1/Inf2) for cost-efficient high-throughput model serving after Neo compile.
JumpStart
SageMaker hub of pre-trained models, notebooks, and fine-tuning recipes.
Knowledge Base (Bedrock)
Managed RAG: document ingestion, chunking, embedding, and retrieval for FM prompts.
Lineage (SageMaker)
Graph tracking artifacts from datasets through jobs to deployed models.
Managed Spot Training
SageMaker Training on Spot instances with checkpoint restart — lower train cost.
Model Card
Documented intended use, metrics, limitations, and ethical considerations for a model version.
Model Monitor
SageMaker service scheduling data quality, drift, and model quality checks on live traffic.
Model package
Versioned, approvable artifact in SageMaker Model Registry referencing inference spec and model data.
Model Registry
Central catalog of model groups/versions with approval workflow for production promotion.
Multi-model endpoint
Single endpoint hosting multiple models on shared compute for A/B or portfolio serving.

03 N – Z

Neo (SageMaker)
Model compilation for optimized deployment on Inferentia, Graviton, or GPUs.
Offline store (Feature Store)
S3-backed historical features for training and batch scoring exports.
Online store (Feature Store)
Low-latency feature lookup store (DynamoDB) for real-time inference.
PEFT
Parameter-efficient fine-tuning — adapters/LoRA on FMs without full weight retrain.
Pipeline (SageMaker)
ML workflow DAG of Processing, Training, Condition, Register, Deploy steps with caching.
Point-in-time correctness
Features computed using only information available at prediction time — prevents leakage.
Processing job
Managed SageMaker compute for ETL, feature generation, and batch data prep.
RAG (retrieval-augmented generation)
Retrieve relevant chunks from a vector index and inject into FM context at invoke time.
Real-time endpoint
Always-on SageMaker HTTPS inference with auto scaling — steady low-latency traffic.
Serverless Inference
SageMaker invoke mode scaling to zero with cold-start trade-off for spiky workloads.
SHAP
Explainability method showing per-feature contribution to individual predictions — via Clarify.
Studio (SageMaker)
Web IDE for notebooks, experiments, pipelines, and registry — prototype before production jobs.
Target leakage
Training features that encode the label or future outcome — invalidates validation metrics.
Train-serve skew
Mismatch between training and serving feature code/pipelines causing prod degradation.
Trainium
AWS training accelerator (Trn instances) for high-throughput deep learning training.
Training job
Managed SageMaker job that produces model artifacts from an algorithm/container on input data.
