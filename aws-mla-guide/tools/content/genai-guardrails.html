GenAI · Guardrails

Guardrails before users see output.

Amazon Bedrock Guardrails filter harmful content, block topics, redact PII, and enforce responsible GenAI policies on both prompts and responses. MLA-C02 stems tie Guardrails to regulated industries — healthcare and banking stories.

01 What Guardrails control

Apply a guardrail to Agents, Knowledge Bases, and InvokeModel flows. Configure denied topics, content filters (hate/violence/sexual), PII redaction/blocking, and word/policy filters — evaluate input and output.

Denied topics
Block investment advice outside approved scope, DIY medical diagnosis, or internal exploit discussion.
PII
Detect/redact SSN, account numbers in prompts or model replies — critical for Ledger Bank chat logs.
Content filters
Standard harmful categories with strength thresholds — tune false positives in staging.
Acme Health
Deny “prescribe dosage” topics; redirect to licensed clinician; filter PHI leakage in outbound text.
Ledger Bank
Block requests for other customers’ data; redact card numbers even if user pastes them.

02 Responsible GenAI exam stems

When stems mention compliance, PII, harmful content, or brand-safe tone, Guardrails beat prompt-only pleading. Combine with KB grounding — Guardrails don’t fix wrong facts, they block unsafe or non-compliant output.

Guardrails handle
  • Topic allow/deny lists
  • PII in user input or model output
  • Harmful / off-brand content classes
  • Central policy reused across Agents/apps
Need something else
  • Factual grounding → Knowledge Base / RAG
  • Auth to APIs → IAM + Agent action groups
  • Audit trail → CloudTrail + logging
  • Model bias on tabular ML → SageMaker Clarify
Common trap gotcha

“Put it in the system prompt.” Prompts are soft guards — exam regulators want Guardrails for enforceable PII redaction and topic denial with consistent API behavior across clients.

03 Exam quiz

Nurse chatbot must never return patient SSNs even if they appear in pasted notes. Central policy across Agent and standalone app. Service?

Right. PII enforcement → Guardrails. Prompts are not reliable; Clarify is for tabular model bias/explainability, not GenAI PII filtering.
