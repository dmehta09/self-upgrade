02 RAG vs fine-tune vs prompt

Prompt only
  • Behavior/style tweaks
  • Zero data pipeline
  • Weakest on private facts
RAG (Knowledge Base)
  • Ground on your docs
  • Chunk + embed + retrieve
  • Exam first for private knowledge
Fine-tune / PEFT
  • Domain tone / task format
  • Needs labeled examples
  • After prompt+RAG insufficient
Agents
  • Multi-step + API tools
  • Action groups → Lambda
  • Not for simple Q&A only

03 Feature Store

Offline vs online

Offline store
Historical exports for training/batch — S3-backed.
Online store
Low-latency key lookup at inference (DynamoDB).
Same feature group
Prevents train-serve skew.
Not Feature Store
Raw Glue table alone; ad hoc Lambda features.

Data integrity

Leakage
Future info in features — fix in prep, not Monitor.
Point-in-time
Features known only at prediction time.
Processing job
Shared transforms for train/score.

04 Model Monitor & ops metrics

Model Monitor
  • Data quality / drift / bias
  • Needs baseline + capture
  • Triggers retrain pipeline
CloudWatch
  • Invocations, latency, 4XX/5XX
  • CPU/GPU util, auto scaling
  • Not statistical feature drift
Clarify
Explainability + bias at train time — not live drift alone.
Guardrails
GenAI content safety at Bedrock invoke.

05 IAM for ML

Never

Registry & pipeline

Model Registry
Approved packages only → prod.
ConditionStep

EventBridge
Drift alarm → StartPipelineExecution.

Audit trail + human-readable risk doc.
