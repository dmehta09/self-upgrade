Data preparation · Feature Store

One feature definition for training and serving.

Train/serve skew breaks production ML. SageMaker Feature Store gives offline stores for training at scale and an online low-latency store for real-time inference — same feature name, same transform logic, consistent values.

01 Online vs offline stores

Write features once via ingestion (Streaming or batch). Offline = historical S3-backed records for Training jobs. Online = millisecond lookups keyed by entity ID at endpoint invoke time.

flowchart LR
  ingest["Feature ingestion"] --> offline["Offline store · S3"]
  ingest --> online["Online store · low latency"]
  offline --> train["Training / batch transform"]
  online --> infer["Real-time endpoint"]
Offline store
Time-series of feature values — point-in-time training queries ("what did we know at T?").
Online store
Latest feature vector per record ID — fraud card features at swipe time.
Feature group
Schema + ingestion pipeline for a related feature set (e.g., ledger-card-features).
Consistency
Same transformation code in Processing ingestion — exam antidote to train/serve skew.
In plain English analogy

Offline store is the hospital archive — every past lab value for research. Online store is the bedside monitor — only what you need right now to decide. Same patient ID, two access patterns.

03 When the exam picks Feature Store

Keywords: same features, real-time inference, historical training, train/serve consistency, multiple models share features. Skip it for one-off batch models with no online path.

Common trap gotcha

Feature Store for RAG embeddings. Vector embeddings for Bedrock Knowledge Bases live in OpenSearch Serverless / vector collections — not SageMaker Feature Store. Feature Store is for structured ML features (numeric/categorical), not document chunk vectors.

Ledger needs identical fraud features for weekly retraining and millisecond authorization scoring. Best AWS service?

Right. Structured features, dual access patterns → Feature Store. Manual dual pipelines invite skew; Knowledge Base is for RAG text.
