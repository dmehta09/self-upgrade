01 Core deck

0/0 known

  • Recite the five CKA domain weights.

    Troubleshooting 30% · Cluster 25% · Networking 20% · Workloads 15% · Storage 10%.

  • Pending vs CrashLoopBackOff — first tool for each?

    Pending → describe Events (schedule/PVC/taints). CrashLoop → logs --previous + exit reason.

  • What does empty Service Endpoints usually mean?

    Selector/label mismatch, no Ready Pods, or port/targetPort mismatch — not DNS yet.

  • Role vs ClusterRole — when which?

    Role: namespaced resources in one ns. ClusterRole: cluster-scoped (nodes, PVs) or reusable rules; bind with RoleBinding or ClusterRoleBinding.

  • kubeadm join worker — required flags?

    API endpoint, --token, --discovery-token-ca-cert-hash. No --control-plane for workers.

  • CRI vs CNI vs CSI in one line each?

    CRI runs containers (containerd). CNI gives Pod IPs/routes. CSI attaches/mounts volumes.

  • What does a NetworkPolicy with empty podSelector: {} select?

    All Pods in the NetworkPolicy’s namespace.

  • Gateway API: what links an HTTPRoute to a Gateway?

    parentRefs (name, namespace, optional sectionName/port) on the HTTPRoute.

  • kubectl apply -k vs helm install?

    -k builds/applies a Kustomize root. Helm installs a chart as a named release with its own lifecycle.

  • rollout undo — what must exist first?

    Revision history on the Deployment (check rollout history). Undo returns to a prior ReplicaSet.

  • Taint NoSchedule vs toleration — enough to pin a Pod?

    No. Toleration allows scheduling onto the tainted node; use nodeSelector/affinity to require it.

  • Why does HPA show <unknown> CPU?

    Missing CPU requests on Pods and/or metrics-server not healthy.

  • liveness vs readiness probe?

    Liveness: restart container if fail. Readiness: remove from Service Endpoints if fail.

  • PVC Pending — top causes?

    No matching PV, wrong access mode, missing/default StorageClass, provisioner failure.

  • How do you mark a StorageClass as default?

    Annotate storageclass.kubernetes.io/is-default-class=true; clear the old default with trailing -.

  • DNS name of Service web in namespace shop?

    web.shop.svc.cluster.local (short forms web.shop.svc / web.shop inside cluster).

  • First 20 seconds of every CKA task?

    kubectl config use-context … and set/check the namespace named in the stem.

  • Pass bar and time box?

    ≥66% in 2 hours on the performance exam (confirm enrollment details).

  • Where do you fix a CrashLooping Deployment Pod?

    On the Deployment (or other owner) — deleting the Pod alone just recreates the same spec.

  • ImagePullBackOff — checklist?

    Image name/tag, registry reachability, imagePullSecrets / service account pulls.

  • drain — common safe flags?

    --ignore-daemonsets and often --delete-emptydir-data; cordon first; uncordon when Ready.

  • Is deep etcd backup a core CKA competency now?

    No — focus control-plane health, kubeadm lifecycle, and workload/node troubleshooting.

  • auth can-i purpose on the exam?

    Verify RBAC after Role/Binding create: kubectl auth can-i … --as=system:serviceaccount:ns:sa.

  • port vs targetPort on a Service?

    port = Service VIP port clients use; targetPort = container (or named) port on the Pod.
