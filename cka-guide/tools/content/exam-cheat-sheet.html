07 Quick check

apply -f vs apply -k? Core

Say it out loud: Dash f is a file or directory of manifests. Dash k runs Kustomize on a kustomization root.

Answer

-f raw manifests; -k Kustomize build+apply. Helm is a separate CLI.

Gateway vs Ingress one-liner? Warm

Say it out loud: Ingress is one resource with annotations; Gateway splits listeners and routes with parentRefs.

Answer

Both expose HTTP(S) to Services. CKA v1.35 expects Gateway API familiarity alongside classic Ingress.
