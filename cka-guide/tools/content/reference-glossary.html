REFERENCE · glossary CKA · K8s v1.35 terms

Glossary.

Short definitions for exam vocabulary. Pair with the cheat-sheet for commands and lessons for depth.

01 Control plane & nodes

kube-apiserver
Only public write path to cluster state; validates and persists objects.
etcd
Consistent key-value store holding desired and observed API objects.
scheduler
Binds unbound Pods to nodes (writes nodeName / binding).
controller-manager
Runs controllers (Deployment, Node, Job, endpoints…) that reconcile desired state.
kubelet
Node agent: watches Pods for this node, drives CRI, reports status.
kube-proxy
Programs Service VIP / load-balancing rules (iptables/IPVS or equivalent datapath).
Static Pod
Manifest on disk watched by kubelet (typical for control-plane components under kubeadm).
Taint / toleration
Node repulsion; Pods need matching tolerations to schedule onto tainted nodes.
Cordon / drain
Mark unschedulable; evict workloads safely before maintenance.

02 Workloads

Pod
Smallest deployable unit: one or more containers sharing network/IPC namespace.
Deployment
Declarative ReplicaSet manager with rolling updates and rollout history.
ReplicaSet
Maintains a stable set of Pod replicas matching a selector.
DaemonSet
One Pod per matching node (agents, CNI helpers, log shippers).
Job / CronJob
Run-to-completion Pods; CronJob schedules Jobs on a timetable.
ConfigMap / Secret
Config data vs sensitive data injected as env or volumes.
livenessProbe
Failure → kubelet restarts the container.
readinessProbe
Failure → Pod removed from Service Endpoints.
requests / limits
Scheduling floor vs hard cap (CPU/memory); HPA usually needs requests.
HPA
Horizontal Pod Autoscaler — scales replicas from metrics (often CPU).
affinity / anti-affinity
Prefer or require Pod/node co-location rules beyond simple selectors.

03 Networking

CNI
Container Network Interface — plugins assign Pod IPs and routes.
ClusterIP
Virtual IP for in-cluster Service access.
NodePort / LoadBalancer
Expose Service outside the cluster via node ports or cloud LB.
Endpoints / EndpointSlice
Ready backend addresses selected by a Service.
NetworkPolicy
Pod-level firewall rules (ingress/egress) enforced by the CNI.
Ingress
Classic L7 HTTP(S) routing resource; needs an Ingress controller.
Gateway API
Modern L7/L4 routing: Gateway + Routes (e.g. HTTPRoute) with parentRefs.
CoreDNS
Cluster DNS; ConfigMap Corefile defines kubernetes and forward plugins.
DNS name
<service>.<namespace>.svc.cluster.local.

04 Storage

Volume
Pod-mounted storage (emptyDir, configMap, PVC, …).
PV
PersistentVolume — cluster storage asset (static or dynamically provisioned).
PVC
PersistentVolumeClaim — user’s request for storage; binds to a PV.
StorageClass
Dynamic provisioning template (provisioner, parameters, reclaim policy).
Access mode
RWO / ROX / RWX / RWOP — how many nodes/Pods may mount.
CSI
Container Storage Interface — volume plugins for attach/mount.
Reclaim policy
Retain or Delete PV when PVC is released.

05 Cluster config & extensibility

kubeadm
Bootstrap and upgrade tool for conformant clusters (init/join/upgrade).
CRI
Container Runtime Interface — kubelet ↔ runtime (usually containerd).
RBAC
Roles/ClusterRoles + bindings authorize API verbs for users/SAs.
ServiceAccount
Identity for processes in Pods calling the API.
Helm
Package manager: charts, releases, values overrides.
Kustomize
Overlay engine; kubectl apply -k builds patches without templates.
CRD
CustomResourceDefinition — extends the API with new kinds.
Operator
Controller that reconciles one or more CRDs for an application.
Admission
Validating/mutating webhooks that intercept API writes before persist.

06 Quick check

Who writes Pod nodeName? Core

Say it out loud: The scheduler binds the Pod — kubelet then runs it on that node.

Answer

Scheduler (via binding). kubelet never invents the placement for normal API-created Pods.

HTTPRoute without parentRefs? Warm

Say it out loud: It is orphaned — no Gateway accepts it, so no traffic path.

Answer

parentRefs attach the route to a Gateway listener. Missing or wrong refs → not Accepted.
