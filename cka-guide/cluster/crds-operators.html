CRDs & operators.

CustomResourceDefinitions extend the API. Operators (controllers) reconcile those custom resources toward a desired state. CKA wants you to install CRDs, create CRs, and know where to look when they stick.

01 The idea

A CRD teaches the API server a new kind. An operator watches instances of that kind and acts — same reconcile loop as Deployments, different domain.

Analogy plain English

CRD is adding a new form type at city hall (“Certificate request”). The operator is the clerk who reads each form and calls the CA, renews dates, and updates the status stamp. Without the clerk, forms pile up Accepted=False forever.

02 Working with CRDs

After install, kubectl api-resources shows the new kind. CR YAML uses the CRD’s group/version/kind. Namespaced vs cluster-scoped follows the CRD’s scope.

example-cr.yaml 
apiVersion: example.com/v1
kind: Widget
metadata:
  name: demo
  namespace: demo
spec:
  size: small
  replicas: 2
discover & manage 
$</span> kubectl apply -f crds.yaml
$</span> kubectl get crd
$</span> kubectl api-resources | grep -i widget
$</span> kubectl explain widget.spec
$</span> kubectl -n demo apply -f example-cr.yaml
$</span> kubectl -n demo get widget demo -o yaml
$</span> kubectl -n demo describe widget demo
Gotcha exam trap

CR applies but nothing happens → operator Deployment/Pod missing or crashing. Check operator logs and CR .status / conditions. Deleting a CRD cascades delete of all CRs of that type — dangerous on a shared cluster.

03 Operators in practice

On CKA you rarely write an operator — you install one (YAML/Helm), create its CR, and verify child objects. Treat status like a Deployment’s conditions.

Healthy path
  • CRD Established=True
  • Operator Pod Running
  • CR status shows Ready / conditions
  • Child Pods/Services appear
Stuck path
  • CRD missing → unknown kind
  • RBAC missing for operator SA
  • Wrong apiVersion on CR
  • Webhook / validation reject

kubectl says “no matches for kind Widget”. First check?

Unknown kind almost always means the CRD isn’t present or you’re using the wrong group/version.

04 Exam rapid-fire

CRD vs Custom Resource? core

CRD defines the schema/kind in the API. A Custom Resource is one instance of that kind.

Say it out loud

“CRD is the type; CR is the object.”

What does an operator do? core

A controller that watches CRs and reconciles related Kubernetes objects (and status) to match spec.

Say it out loud

“Operator = human ops knowledge encoded as a reconcile loop on CRs.”

CR created, no child Pods — checklist? stretch

Operator Deployment healthy, RBAC for its SA, CR status/events, correct namespace, validating webhooks not rejecting, image pulls for children.

Say it out loud

“I check the operator before I rewrite the CR — no controller, no children.”
