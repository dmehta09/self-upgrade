Helm & Kustomize.

CKA expects you to install and change workloads with both Helm (charts/releases) and Kustomize (overlays via kubectl apply -k). Pick the tool the task names.

01 The idea

Helm packages templates into a release you upgrade/rollback. Kustomize patches plain YAML without a templating language — bases + overlays.

Analogy plain English

Helm is a meal kit with a versioned recipe card (chart) and a receipt (release history). Kustomize is labeling leftovers in your fridge: same ingredients (base YAML), different stickers and spice packets (patches) per kitchen (overlay).

02 Helm on the exam

Know install, upgrade, rollback, uninstall, and values overrides. Releases live in a namespace.

helm lifecycle 
$</span> helm repo add bitnami https://charts.bitnami.com/bitnami
$</span> helm repo update
$</span> helm install web bitnami/nginx -n demo --create-namespace -f values.yaml
$</span> helm upgrade web bitnami/nginx -n demo --set image.tag=1.27
$</span> helm history web -n demo
$</span> helm rollback web 1 -n demo
$</span> helm list -A
$</span> helm uninstall web -n demo
Gotcha exam trap

Wrong namespace → “release not found.” helm upgrade --install is the idempotent pattern. Chart values paths differ — helm show values before guessing --set keys.

03 Kustomize on the exam

A directory with kustomization.yaml lists resources and patches. Apply with kubectl apply -k <dir>.

overlay/kustomization.yaml 
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
- ../../base
namespace: demo
images:
- name: myapp
  newTag: "1.35"
replicas:
- name: myapp
  count: 3
patches:
- target:
    kind: Deployment
    name: myapp
  patch: |-
    - op: replace
      path: /spec/template/spec/containers/0/env/0/value
      value: prod
apply overlay 
$</span> kubectl kustomize overlay/ | less
$</span> kubectl apply -k overlay/
$</span> kubectl get deploy -n demo

Task: “Use the overlay in prod/ to set replicas to 5.” Best tool?

Overlays scream Kustomize. apply -k builds and applies the rendered manifests.

04 Exam rapid-fire

Helm release vs chart? core

A chart is the package (templates + values). A release is an installed instance with revision history.

Say it out loud

“Chart is the recipe; release is this kitchen’s cook of it.”

How do you apply a Kustomize overlay? core

kubectl apply -k <dir> where the directory contains kustomization.yaml. Preview with kubectl kustomize.

Say it out loud

“apply -k on the overlay directory — never hand-apply only the base if the task says overlay.”

Bad Helm upgrade — recover? stretch

helm history then helm rollback <release> <revision> in the correct namespace.

Say it out loud

“History, then rollback to the last good revision.”
