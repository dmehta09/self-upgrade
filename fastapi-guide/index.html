What FastAPI actually does

When a request hits your app, FastAPI runs it through a short, predictable pipeline. Almost everything in this guide is one stage of this picture — so keep it in mind.

The life of a request
request
POST /items
JSON + headers
route
match path
→ your function
validate
Pydantic
parse & check types
your code
handler runs
returns an object
response
serialize
→ JSON + status
If validation fails, FastAPI short-circuits with a 422 before your code ever runs — and documents the whole thing at /docs automatically.
Think of a strict receptionist analogy

FastAPI is the receptionist at the front desk. It reads each visitor's form (the request), checks every field is filled in correctly (validation), and only then sends them through to the right office (your function). Fill the form in wrong and you're politely turned away with a note explaining exactly what was missing — that note is the 422.

A note on version numbers

These packages ship often — the exact patch you install will differ. What stays stable: Pydantic v2 and the Annotated + Depends style are the modern baseline. Pin a minor range (e.g. fastapi>=0.136,<0.140) and you'll be fine.

PackageVersion (PyPI)What it is
python3.13.xThe language — use modern type hints (list[int], X | None)
fastapi0.136.xThe web framework
