Python · setup & tooling

Get a Python workspace ready in five minutes.

FastAPI is just Python, so we need a working Python first. Here's the shortest path: install Python, make an isolated environment, install the libraries, and run your first file. Then we'll meet the green “Run” boxes you'll use throughout the guide.

1 · Install Python 3.13+

Check whether you already have a recent Python:

terminal
python3 --version
# -> Python 3.13.2  (anything 3.10+ works; 3.13 is what we target)

No Python, or an old one? Grab the installer from python.org/downloads (Windows & macOS), or use your package manager (brew install python, apt install python3). On Windows, tick “Add Python to PATH” during install.

Windows: use py

On Windows the command is usually py instead of python3 — e.g. py --version, py -m venv .venv.

2 · Make a virtual environment

A virtual environment is a private box of packages for one project, so installs never collide between projects. Create and activate one in your project folder:

terminal
# create it (a .venv folder appears)
python3 -m venv .venv

# activate it
source .venv/bin/activate        # macOS / Linux
.venv\Scripts\activate           # Windows (PowerShell / cmd)

# your prompt now shows (.venv) — you're inside the box
Even faster: uv

uv is a modern, very fast tool that replaces venv + pip. After installing it: uv venv then uv pip install fastapi. Either approach is fine — we'll write plain pip commands so they work everywhere.

3 · Install FastAPI & a server

Inside the activated environment, install the two things every FastAPI app needs — the framework and a server to run it:

terminal
pip install "fastapi[standard]"
# this pulls in fastapi, pydantic, starlette, AND uvicorn + the `fastapi` CLI

The [standard] extra is the easy button: it bundles uvicorn (the server) and a few helpers, and gives you the fastapi command-line tool. Later pages add sqlmodel, pyjwt, and others as we need them.

4 · Run a Python file

Put this in a file called hello.py and run it with python hello.py:

hello.py
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("FastAPI"))

5 · Or just press “Run” right here

Throughout this guide you'll see green Run boxes like the one below. They execute real Python in your browser — edit the code, hit Run, and see the output. Try changing the name:

hello.py
Hello, FastAPI!
How the Run boxes work

The first time you press Run, the page downloads a small Python runtime (Pyodide) — so that one needs an internet connection and takes a few seconds. After that it's instant. No internet? The box simply shows the saved expected output instead, so you never lose the lesson. Note: these run pure Python — to run a real server you still use uvicorn on your own machine.

6 · Preview: running the server

You won't run a server here in the browser, but here's the command you'll use on your own machine once you've written an app (we build one starting in the FastAPI section):

terminal
fastapi dev main.py      # dev server with auto-reload, on http://127.0.0.1:8000
# (equivalent to: uvicorn main:app --reload)

Then open http://127.0.0.1:8000/docs for interactive API docs FastAPI builds for you — more on that soon.
