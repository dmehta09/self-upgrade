Python · the refresher

The Python you need for FastAPI.

Five short topics, each with code you can run. We're not covering all of Python — just the parts FastAPI leans on. The big one is type hints: FastAPI reads them to validate requests and build your docs, so they're worth real attention.

01  Variables & types

Python variables don't need a declared type — you assign and go. But every value has a type, and you can ask for it. The everyday types you'll use in APIs: str, int, float, bool.

types.py
Ada 36 1.7 True
int float

An f-string (the f"..." prefix) drops values into text with {} — you'll use these constantly.

02  Functions

Functions are defined with def. They can have default values, accept any number of positional arguments with *args, and keyword arguments with **kwargs. FastAPI route handlers are just functions, so this is the shape of everything you'll write.

functions.py
60.0
66.0

In def total(*prices, tax=0.0), how do you pass tax?

Right. Anything after *prices is “keyword-only” — you must name it. That's exactly how FastAPI's Query(), Depends() and friends are passed too.

03  Data structures

Four containers cover almost everything: list (ordered, []), dict (key→value, {}), set (unique items), and tuple (fixed, ()). A JSON object maps cleanly onto a Python dict — keep that in mind for APIs.

A comprehension builds a list (or dict/set) in one readable line:

structures.py
[1, 9, 25]
Ada -> admin
default
dict.get(key, default) is safer

user["missing"] raises a KeyError; user.get("missing", "default") returns a fallback instead. Handy when data might be absent.

04  Type hints the key idea

A type hint annotates what type a variable, argument, or return value should be: name: str, -> bool. Python doesn't enforce them at runtime — but FastAPI does. It reads your hints to parse and validate incoming data and to generate documentation. Learn this and FastAPI stops feeling magic.

Modern hint syntax (Python 3.10+)
x: int
a single value's type
items: list[str]
a list of strings (built-in generics, no imports)
data: dict[str, int]
a dict from string keys to int values
nickname: str | None
a string or None (“optional”)
-> float
the function returns a float
hints.py
Ada is 36
Amazing Grace is 45
You'll also see Annotated

FastAPI's modern style attaches extra info to a hint with Annotated[type, ...] — e.g. Annotated[str, Query(max_length=50)]. It's just “this is a str, and here's some metadata about it.” We use it from the routing page onward.

What does FastAPI do with the hint age: int on a request parameter?

Exactly. FastAPI turns your type hints into real validation. age: int means “coerce this to an integer, or reject the request with a clear error.” That's why hints matter so much here.

05  async / await

Web servers spend most of their time waiting — for a database, another API, the network. async lets one process handle many requests during that waiting, instead of sitting idle. You write async def for such a function and await the slow calls inside it.

In a real script you start the async world with asyncio.run(main()):

async_script.py
import asyncio

async def fetch(name: str) -> str:
    await asyncio.sleep(0)        # pretend to wait on I/O
    return f"got {name}"

async def main() -> None:
    # run two "I/O" calls concurrently
    results = await asyncio.gather(fetch("users"), fetch("orders"))
    print(results)

asyncio.run(main())

The runnable version below does the same thing — the in-browser runner already provides the async loop, so we can await at the top level directly:

async_demo.py
['got users', 'got orders']
async only helps if you await async libraries

Putting async def on a function that then does slow blocking work (a normal database driver, time.sleep) gives you no benefit and can freeze the server. We cover exactly when to use async def vs plain def on the Advanced page.

Exercise

Write initials(full_name: str) -> str that turns a name into uppercase initials.

For example, initials("ada lovelace") should return "A.L.". Try it in the runner, then check the solution.

exercise.py
(write your solution and press Run)
Show solution solution
solution.py
def initials(full_name: str) -> str:
    return ".".join(part[0].upper() for part in full_name.split()) + "."

print(initials("ada lovelace"))   # -> A.L.

full_name.split() breaks on spaces; the generator takes each part's first letter, upper-cases it, and ".".join(...) stitches them together. The trailing + "." adds the final dot.
