FastAPI · auth & security

Logins, tokens, and protected routes.

Real apps need to know who is calling and what they're allowed to do. We'll hash passwords safely, implement the standard OAuth2 password flow, issue signed JWT tokens, and gate endpoints behind a “current user” dependency.

01  Authentication vs authorization

Authentication
Who are you? Proving identity — logging in with a username and password.
Authorization
What may you do? Checking permissions — “is this user an admin?”

The flow we build: the user logs in once (authentication) and gets a token; every later request carries that token, and a dependency turns it back into a user (and can then check authorization).

02  Never store plain passwords — hash them

You must never save a password as-is. Instead store a one-way hash; on login you hash the attempt and compare. Use pwdlib (the currently recommended library) with a strong algorithm like Argon2.

security.py
# pip install "pwdlib[argon2]"
from pwdlib import PasswordHash

password_hash = PasswordHash.recommended()

hashed = password_hash.hash("s3cret")          # store THIS, never the plaintext
print(password_hash.verify("s3cret", hashed))  # True
print(password_hash.verify("wrong", hashed))   # False
Old tutorials use passlib + python-jose

Both are effectively unmaintained now. This guide uses pwdlib for hashing and PyJWT for tokens — the libraries FastAPI's current docs recommend. If you copy old code using passlib or jose, expect breakage on modern Python.

03  The OAuth2 password flow

FastAPI ships helpers for the standard flow. OAuth2PasswordBearer tells FastAPI where the login endpoint is and how to read the token; OAuth2PasswordRequestForm parses the username/password the client posts as form data.

login.py
from typing import Annotated
from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")   # the login URL

@app.post("/token")
def login(form: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = get_user(form.username)
    if not user or not password_hash.verify(form.password, user.hashed_password):
        raise HTTPException(status_code=401, detail="Incorrect username or password")
    token = create_access_token({"sub": user.username})
    return {"access_token": token, "token_type": "bearer"}

04  JWT with PyJWT

A JWT (JSON Web Token) is a signed string that encodes a small payload (like the username) plus an expiry. Because it's signed with your secret key, the server can trust it without a database lookup. Use PyJWT to create and verify them.

tokens.py
# pip install "pyjwt[crypto]"
import jwt
from datetime import datetime, timedelta, timezone

SECRET_KEY = "change-me-and-load-from-env"   # NEVER hard-code in real apps
ALGORITHM = "HS256"

def create_access_token(data: dict, minutes: int = 30) -> str:
    payload = data.copy()
    payload["exp"] = datetime.now(timezone.utc) + timedelta(minutes=minutes)
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)

def decode_access_token(token: str) -> dict:
    # raises jwt.ExpiredSignatureError / jwt.InvalidTokenError on bad tokens
    return jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
A JWT is signed, not encrypted

Anyone can read a JWT's payload — so never put secrets in it. The signature only guarantees it wasn't tampered with. Always set an exp so tokens don't live forever, and keep SECRET_KEY out of your code (load it from an environment variable).

05  Protecting routes

Tie it together with a dependency that reads the token, decodes it, and returns the user — or raises 401. Any endpoint that asks for CurrentUser is now protected.

protect.py
TokenDep = Annotated[str, Depends(oauth2_scheme)]

def get_current_user(token: TokenDep):
    creds_error = HTTPException(
        status_code=401, detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = decode_access_token(token)
        username = payload.get("sub")
        if username is None:
            raise creds_error
    except jwt.InvalidTokenError:        # covers expired + malformed
        raise creds_error
    user = get_user(username)
    if user is None:
        raise creds_error
    return user

CurrentUser = Annotated[User, Depends(get_current_user)]

@app.get("/users/me")
def read_me(user: CurrentUser):          # 401 unless a valid token is sent
    return {"username": user.username}

Why is it safe for the server to trust a JWT without looking it up in a database?

Right. The signature proves the token was issued by your server and hasn't been altered. It isn't encrypted (the payload is readable), and good tokens do expire via exp.
