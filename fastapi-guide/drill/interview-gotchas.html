Interview gotchas

Backend verbal screens poke at lifecycle, DI, async DB, JWT, and tests — not framework trivia. Plain answers first, then the keywords that show you ship modern FastAPI (Pydantic v2, Annotated, lifespan, pwdlib).

01  What they grade

request path
Validation → deps → handler → response model. Failures return 422 before your code runs.
resources
yield deps for session teardown; lifespan for app startup/shutdown (not deprecated on_event).
async honesty
No blocking I/O in async def; await every async session call; eager-load relationships.
auth reality
JWT is signed, not encrypted; secrets in env; refresh + RBAC for anything beyond a demo.

02  Highest-frequency questions

#QuestionSay this (compress)Open
1 Walk a request through FastAPI Routing → path/query/body validation (Pydantic) → dependency tree → handler → response_model filter/serialize. Bad input = 422 before the handler. Overview / reqtrace
2 How do you do DI today? Annotated[T, Depends(fn)] aliases. Prefer that over bare Depends in signatures. Sub-deps resolve once per request (cached). Dependencies
3 When do you yield in a dep? Setup before yield, teardown after (session close). Runs after the response is sent — success or error. Yield deps
4 async def vs def? async def for awaitable I/O. Plain def for blocking libraries — FastAPI runs it in a threadpool. Blocking inside async def freezes the loop. Async & structure
5 Why MissingGreenlet? Lazy relationship load after the async session context. Fix with selectinload / explicit join while the session is open. Async DB
6 Data “saves” then vanishes? Forgot await session.commit() — coroutine created and discarded. Grep un-awaited session calls first. Async DB
7 SQLAlchemy query style? Use session.exec(select(...)) with SQLModel — not legacy session.query. SQLModel
8 Startup / shutdown? Lifespan context manager on the app. on_event("startup") is the old pattern — say lifespan. Lifespan
9 JWT — encrypted? No — signed (integrity + authN). Claims are readable unless you also encrypt. Keep secrets in env; short-lived access + refresh. OAuth2 & JWT
10 Password hashing library? pwdlib (Argon2) + PyJWT — not unmaintained passlib / python-jose. Auth
11 Auth beyond login demo? Refresh tokens, RBAC via role deps, API keys for services. Protect routes with CurrentUser / require_roles. Auth II
12 How do you test async apps? TestClient for sync suites. Async fixtures / concurrent calls → httpx.AsyncClient + ASGITransport. Override deps for a test DB. Async tests

Stale / wrongCurrent (mid-2026)

Opening line say it

“I structure apps with routers and lifespan, inject sessions via Annotated yield deps, keep handlers async-honest, use SQLModel select/exec, ship JWT with pwdlib+PyJWT plus refresh/RBAC, and test with TestClient or AsyncClient depending on the suite.”
