Exam prep · SAA-C03 domains

Four domains. One architecture brain.

SAA-C03 scores you on Secure · Resilient · High-performing · Cost-optimized. This map shows which guide modules feed each domain — study by domain when a mock exposes a weak area.

01 Official domains at a glance

DomainWeight (approx.)What "good" looks like
1 · Design Secure Architectures~30%IAM least privilege, encryption, network isolation, edge protection, detective controls
2 · Design Resilient Architectures~26%Multi-AZ, decoupling, DR/RPO/RTO, backups, failover
3 · Design High-Performing Architectures~24%Right storage/compute/DB, caching, edge, scaling, networking performance
4 · Design Cost-Optimized Architectures~20%Pricing models, right-size, storage classes, data transfer, Budgets/Explorer

Weights shift slightly over time — confirm against the current AWS exam guide. Mentally tag every practice question with a domain.

03 How to use this map

  1. Finish Exam method so you know how stems hide the domain.
  2. Run the timed mock — note weak domain bars.
  3. Drill that domain's modules, then the scenario bank filtered mentally by chip.
  4. Night-before: cheat-sheet + flashcards.

04 Quick self-check

Stem: "encrypt at rest and in transit, least privilege." Domain?warm-up
Answer

Secure (Domain 1) — KMS, TLS, IAM roles. Cost/perf may appear as distractors.

Stem: "RTO 15 min, survive Region failure." Domain?core
Answer

Resilient (Domain 2) — multi-Region DR warmth. Secure encryption is assumed, not the primary ask.

Stem: "minimize cost for fault-tolerant batch." Domain?core
Answer

Cost-optimized (Domain 4) — Spot / Graviton / right-size, while still meeting the resilience constraint.
