WAF, Shield & edge protection.

Stop volumetric and application-layer attacks before they hit your origin. Pair CloudFront / ALB / API Gateway with AWS WAF, and know when Shield Standard vs Advanced matters.

01 Edge protection stack

Defense in depth at the edge: DNS (Route 53) → CDN (CloudFront) → WAF rules → Shield DDoS → origin (ALB/S3/custom) locked to the edge.

In plain English analogy

Shield is the riot police for floods of traffic (DDoS). WAF is the bouncer reading IDs and bag checks — SQL injection payloads, bad bots, geo blocks. CloudFront is the vestibule so attackers hammer the lobby, not your kitchen (origin).

02 AWS WAF essentials

Web ACL
Collection of rules attached to CloudFront, ALB, API Gateway, or AppSync.
Managed rule groups
AWS / marketplace packs for SQLi, XSS, known bad inputs — start here on the exam.
Rate-based rules
Throttle abusive IPs (login scraping, credential stuffing).
Geo / IP sets
Allowlist partners or denylist regions; combine with labels and custom responses.
Bot Control
Optional managed capability for sophisticated bots (costlier — know it exists).
WAF association
  • CloudFront — global apps, static+dynamic
  • ALB — Regional HTTP apps without CDN
  • API Gateway — HTTP APIs / REST APIs
Not WAF’s job
  • Pure L3/L4 volumetric floods → Shield
  • AuthZ inside the app → IAM / Cognito / JWT
  • Encrypting disks → KMS
Common trap gotcha

Attaching WAF to CloudFront while leaving the ALB/S3 origin open to the world lets attackers bypass the edge. Lock origins with CloudFront prefix lists / custom headers / OAC (S3) / private connectivity patterns.

Exam cueDefault protection“Mission-critical,” “24/7 SRT,” “DDoS cost protection,” advanced metrics

A global marketing site faces SQLi probes and needs caching. Which design fits?

Right. Application-layer attacks → WAF at the edge; CloudFront for global cache. SGs alone don’t parse HTTP payloads; KMS isn’t for TLS cert “SQLi defense.”

04 Interview rapid-fire

WAF vs Shield — one sentence each?core
Model answer

WAF filters HTTP(S) requests with rules (SQLi, XSS, rate, geo). Shield mitigates DDoS at the network/transport layers (and Advanced adds operational support and extra protections). Often used together in front of CloudFront or ALB.

Say it out loud say it

"WAF is the L7 bouncer; Shield is DDoS protection. Standard is free baseline; Advanced is for critical apps that need SRT and cost protection."

Where do you attach a Web ACL?warm-up
Model answer

To CloudFront distributions, Application Load Balancers, API Gateway stages, or AppSync. Pick CloudFront for global edge filtering; ALB/API GW for Regional apps.

Say it out loud say it

"Web ACL on CloudFront for global, on ALB or API Gateway when the app is Regional-only."

How do you stop origin bypass?stretch
Model answer

Don’t leave the origin world-open. Use Origin Access Control for S3, require a secret header checked by the ALB/app, or restrict SG/NACL to CloudFront managed prefix lists so only the CDN can reach the origin.

Say it out loud say it

"WAF on CloudFront is useless if the ALB is still public — lock the origin so only the edge can talk to it."
