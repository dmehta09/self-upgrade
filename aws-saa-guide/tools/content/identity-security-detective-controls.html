Detective controls.

Preventive IAM is not enough. SAA expects you to wire CloudTrail, Config, GuardDuty, Security Hub, and CloudWatch so misconfigs and threats surface fast — centrally in multi-account orgs.

01 CloudTrail & Config

CloudTrail answers “who did what, when?” Config answers “what does my inventory look like, and is it compliant?”

In plain English analogy

CloudTrail is the building’s CCTV + badge log — every door open is recorded. Config is the nightly inventory clipboard: “are all fire extinguishers still mounted and tagged?” GuardDuty is the guard watching the feeds for suspicious patterns.

Org trail
One trail in the management / delegated admin account covering all members; logs to a locked log-archive bucket.
Management vs data events
Management events = control plane (default). Data events = S3 object-level / Lambda invoke — costlier, enable when needed.
Config rules
Managed rules (encrypted volumes, public buckets) + custom; remediate with SSM Automation.
Config aggregator
Multi-account / multi-Region compliance view.
Common trap gotcha

CloudTrail is not a real-time IDS by itself. Pair with GuardDuty (threat intel on CloudTrail/VPC Flow/DNS) and alarms on metric filters for break-glass events. Also: never leave the trail bucket writable by everyone — that destroys evidence integrity.

Metrics & alarms

Logs Insights

Metric filters

PrivateLink mindset

04 Interview rapid-fire

CloudTrail vs Config vs GuardDuty?core
Model answer

CloudTrail records API activity. Config records resource configuration and evaluates rules. GuardDuty analyzes CloudTrail, VPC Flow, and DNS logs for threat findings. Use all three in a mature account baseline.

Say it out loud say it

"Trail is the audit log, Config is inventory and compliance, GuardDuty is the threat detector watching those signals."

How do you centralize findings in Organizations?core
Model answer

Delegated administrator for GuardDuty / Security Hub / Config; org CloudTrail into a log-archive account with tight bucket policies; aggregate Config; Security Hub as the consolidation layer. SCPs prevent members from disabling logging.

Say it out loud say it

"Org trail to log-archive, delegated GuardDuty and Security Hub, Config aggregator — SCPs so nobody turns the cameras off."

When do you enable CloudTrail data events?stretch
Model answer

When you need object-level S3 or Lambda invoke auditing — forensics, sensitive buckets, regulated workloads. They cost more and generate volume, so scope to critical resources rather than everything by default.

Say it out loud say it

"Management events by default; data events when I must know which object or which Lambda invoke happened — scoped, because they’re pricey."
