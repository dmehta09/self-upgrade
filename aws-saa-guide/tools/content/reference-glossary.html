SAA glossary, A–Z.

Crisp definitions for Solutions Architect – Associate vocabulary. AWS-first, September 2026. For interview-depth DevOps AWS phrasing, see the companion DevOps AWS module.

01 A – F

ALB (Application Load Balancer)
Layer-7 load balancer for HTTP/HTTPS with host/path routing; integrates with WAF and target groups.
Aurora
AWS-managed MySQL/PostgreSQL-compatible engine with Multi-AZ storage and fast failover; Global Database for multi-Region.
Auto Scaling Group (ASG)
Keeps a desired count of healthy EC2 instances and scales in/out across AZs on policies.
Availability Zone (AZ)
Isolated location within a Region (one or more data centers) with independent power and networking.
AWS Backup
Central backup policies and restore for supported AWS resources (EBS, RDS, DynamoDB, EFS, and more).
AWS Config
Records resource configuration history and evaluates compliance with Config Rules.
AWS Organizations
Multi-account hierarchy with consolidated billing and SCPs as permission guardrails.
Budgets
Thresholds on cost, usage, or Savings Plans/RI coverage that notify (or act) via SNS.
CloudFront
Global CDN that caches content at edge locations; often fronted with OAC to private S3.
CloudTrail
API activity log (who did what, when) delivered to S3 or CloudTrail Lake for audit.
CloudWatch
Metrics, logs, alarms, and dashboards for operational health and performance.
Cost Explorer
Interactive billing analytics and forecasts filtered by service, account, tag, and more.
CUR (Cost and Usage Report)
Line-item billing export to S3 for Athena/QuickSight analysis.
DynamoDB
Fully managed key-value / document NoSQL database with on-demand or provisioned capacity.
EBS
Elastic Block Store — network-attached block volumes scoped to an AZ for EC2.
EFS
Elastic File System — Multi-AZ NFS/POSIX shared filesystem for many clients.
EventBridge
Serverless event bus with rules, filters, schedules, and SaaS partner integrations.
Fargate
Serverless compute for containers on ECS/EKS — no EC2 node management.

02 G – N

Gateway VPC endpoint
Private route-table-based access to S3 or DynamoDB without NAT or public IPs.
Global Tables
DynamoDB multi-Region active-active replication for low-latency global apps.
Graviton
AWS ARM-based CPUs offering strong price/performance versus comparable x86.
IAM
Identity and Access Management — users, roles, policies, and federation for AWS APIs.
Identity Center
Workforce single sign-on into AWS accounts and apps (successor naming to AWS SSO).
Intelligent-Tiering
S3 storage class that automatically moves objects between access tiers as patterns change.
Interface VPC endpoint (PrivateLink)
ENI-based private connectivity to AWS services or NLB-fronted providers.
KMS
Key Management Service — create and control CMKs for encryption at rest and signing.
Lambda
Event-driven serverless functions billed per invoke and duration.
Least privilege
Grant only the permissions required for a task — default security posture on SAA.
Multi-AZ
Deploying across Availability Zones so one AZ failure does not take the service down.
NACL
Network ACL — stateless subnet firewall supporting allow and deny rules.
NAT Gateway
Managed egress from private subnets to the internet without inbound exposure.
NLB (Network Load Balancer)
Layer-4 load balancer for TCP/UDP/TLS with extreme performance and static IPs.

03 O – Z

OAC (Origin Access Control)
Modern CloudFront→S3 private origin pattern replacing legacy OAI for most new designs.
Pilot light
DR strategy keeping data (and minimal core) warm while scaling most compute at failover.
PrivateLink
Brand for private connectivity via interface endpoints / NLB service endpoints.
Region
Geographic area containing multiple AZs; the unit of multi-Region DR and data residency.
Reserved Instance (RI)
Capacity/pricing commitment for specific instance attributes — less flexible than Compute Savings Plans.
Route 53
AWS DNS service with routing policies (failover, latency, geolocation, weighted) and health checks.
RPO
Recovery Point Objective — maximum acceptable data loss measured in time.
RTO
Recovery Time Objective — maximum acceptable time to restore service after an incident.
Savings Plans
Flexible $/hour compute commitment discounting EC2, Fargate, and/or Lambda usage.
SCP
Service Control Policy — Organizations permission ceiling on member accounts.
Security group
Stateful allow-list firewall attached to ENIs/instances; return traffic is automatic.
SNS
Simple Notification Service — pub/sub fan-out to email, Lambda, SQS, HTTP, and more.
Spot Instance
Discounted EC2 capacity that can be reclaimed with short notice — for interruptible work.
SQS
Simple Queue Service — managed message queue (Standard or FIFO) decoupling producers and consumers.
VPC
Virtual Private Cloud — your isolated AWS network of subnets, routes, gateways, and firewalls.
WAF
Web Application Firewall — Layer-7 rules protecting apps (often on CloudFront or ALB).
Warm standby
DR strategy running a scaled-down but complete environment ready to scale out at failover.
Well-Architected Framework
AWS design pillars (operational excellence, security, reliability, performance, cost, sustainability) guiding architecture reviews.
