S3 storage classes & access.

Object storage for durable blobs, data lakes, and static assets. The exam asks which class fits the access pattern — and how you lock the bucket down. As of 2026, treat Intelligent-Tiering as the default when access is unknown or changing.

01 Storage classes — pick by access

S3 is a Regional object store (99.999999999% durability design target). You choose a storage class per object (or let lifecycle / Intelligent-Tiering move it). Cheaper classes trade retrieval cost, latency, or availability.

In plain English analogy

Think of a warehouse with climate-controlled floors. Standard is the front aisle — instant grab, highest rent. Intelligent-Tiering is a smart forklift that moves pallets to cheaper floors when nobody touches them, then brings them back when someone asks — no retrieval fee for the automated moves. Glacier Deep Archive is the off-site vault: pennies to store, hours and a fee to open.

Common trap gotcha

Do not dump everything into Glacier “to save money” if the question needs millisecond reads — pick Instant Retrieval or keep hot/IA. Also: One Zone-IA is cheaper but dies with that AZ; exam scenarios that mention “must survive AZ failure” rule it out.

02 Lifecycle, versioning & replication

Lifecycle rules
Transition classes or expire objects/versions after N days. Pair with Intelligent-Tiering or explicit IA/Glacier transitions.
Versioning
Keeps prior object versions; protects against overwrite/delete. Enables MFA Delete and Object Lock patterns.
CRR / SRR
Cross-Region or Same-Region Replication for DR, latency, or compliance. Needs versioning on.
Object Lock
WORM retention (compliance / governance mode) — exam favorite for “cannot be deleted by anyone.”

03 Access control & private paths

Block Public Access on (account + bucket). Prefer bucket policies + IAM roles over ACLs. Public websites go through CloudFront (OAC), not an open bucket.

Anti-pattern
  • Public bucket for “simple static site”
  • Long-lived access keys in the app
  • ACLs as the primary control plane
Exam-default
  • Block Public Access + CloudFront OAC
  • Instance/task/role credentials
  • VPC gateway/interface endpoints for private access
Presigned URLs
Time-boxed GET/PUT for a specific object without opening the bucket.
Access Points / Multi-Region Access Points
Scoped policy endpoints; MRAP for global anycast-style access.
Encryption
SSE-S3, SSE-KMS, or client-side. KMS when you need key policy audit/control.

Logs arrive with unpredictable access after 30 days. Compliance needs AZ resilience. Best storage approach?

Right. Unknown/changing access → Intelligent-Tiering (2026 default). AZ resilience rules out One Zone. EBS is block storage for instances, not the object archive pattern.

04 Interview rapid-fire

When do you choose Intelligent-Tiering vs Standard vs Glacier?core
Model answer

Standard for hot, predictable frequent access. Intelligent-Tiering when access is unknown or changes over time — it auto-moves between tiers without retrieval fees for those moves (you pay a small monitoring fee). Glacier family for true archive: Instant if you still need ms reads; Flexible/Deep when hours and lowest storage cost are OK.

Say it out loud say it

"Hot and known → Standard. Unknown or changing → Intelligent-Tiering. True cold archive → Glacier, Instant if I still need milliseconds."

How do you serve public content without a public bucket?warm-up
Model answer

Keep Block Public Access on. Put objects in a private bucket and put CloudFront in front with Origin Access Control so only the distribution can read. Users hit the CDN edge, never the bucket URL.

Say it out loud say it

"Private bucket, Block Public Access on, CloudFront with OAC — the CDN is the only reader."

Versioning vs Object Lock — what's the difference?stretch
Model answer

Versioning keeps prior versions so overwrites/deletes are recoverable. Object Lock adds WORM retention so even privileged users cannot delete or overwrite until the retention period ends (compliance or governance mode). Often used together for regulated archives.

Say it out loud say it

"Versioning is undo; Object Lock is WORM — nobody deletes until the clock expires."
