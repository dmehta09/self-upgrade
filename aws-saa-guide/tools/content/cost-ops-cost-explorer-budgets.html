02 AWS Budgets

Set cost, usage, or Savings Plans / RI coverage budgets. Notify via SNS/email; optionally trigger actions (e.g. apply an IAM policy to deny expensive launches — used carefully).

Good Budgets use
  • Alert at 50% / 80% / 100% forecasted
  • Per account or tagged project
  • Usage budgets for data transfer or Spot
Weak use
  • One org-wide budget, no owners
  • Alert-only with nobody on-call for FinOps
  • Blind auto-deny without an exception path
Common trap gotcha

Tags only allocate cost after you activate cost allocation tags in Billing. Untagged resources dump into "no tag" — the exam loves that gotcha. Also: Budgets ≠ Cost Anomaly Detection (different product for unusual spikes).

03 Allocation & multi-account

  • User-defined cost allocation tags — e.g. Project, Environment, Team.
  • AWS Organizations + linked accounts → Cost Explorer by account; SCPs limit blast radius.
  • CUR (Cost and Usage Report) to S3 for Athena/QuickSight when Explorer isn't enough.
  • Cost Anomaly Detection for ML-ish "this looks weird" alerts.

Leadership wants each product team charged for its own AWS spend and alerted at 80% of monthly target. What do you enable?

Right. Chargeback needs activated allocation tags (or account-per-team) plus Budgets for thresholds; Explorer explains variance.

04 Exam rapid-fire

Cost Explorer vs Budgets?warm-up
Model answer

Explorer analyzes historical and forecasted spend. Budgets watches thresholds and notifies (or acts). You usually need both: explore to understand, budget to stay honest.

Say it out loud say it

"Explorer is the microscope; Budgets is the smoke alarm."

Why don't my tags show in Cost Explorer?core
Model answer

They must be marked as cost allocation tags in Billing (and can take up to ~24h). Tagging in the console alone isn't enough for chargeback reports.

Say it out loud say it

"Tag the resource, then activate the tag for billing — two steps."

When reach for CUR?core
Model answer

When you need line-item detail, custom BI, or multi-year analysis beyond Explorer's UI — deliver CUR to S3 and query with Athena/QuickSight.

Say it out loud say it

"Explorer for humans; CUR for warehouses."
