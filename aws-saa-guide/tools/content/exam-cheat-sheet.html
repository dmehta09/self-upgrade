01 Load balancing & compute

ALB vs NLB vs GWLB

ALB (L7)
  • HTTP/HTTPS, path/host rules
  • WAF integration
  • Microservices / containers
NLB (L4)
  • TCP/UDP/TLS
  • Ultra-low latency
  • Static IPs / PrivateLink

GWLB = third-party appliances inline. Classic LB = legacy distractor.

Compute pick

EC2 + ASG
Full control, steady or custom AMI.
ECS/Fargate
Containers without managing servers.
EKS
Managed K8s when you need the ecosystem.
Lambda
Event-driven, spiky, short tasks.

03 Multi-AZ vs multi-Region & DR

Multi-AZ
  • Survive one AZ
  • RDS Multi-AZ, ALB/ASG spread
  • Default HA answer
Multi-Region
  • Survive Region event
  • CRR, Global Tables, Aurora Global
  • Route 53 failover

04 Messaging & identity

SQS vs SNS vs EventBridge

SQS
  • Queue / buffer
  • Pull consumers
  • Standard vs FIFO
SNS
  • Pub/sub fan-out
  • Push to many
  • SNS→SQS durable

EventBridge = bus + rules + SaaS partners + schedules.

KMS

06 Last-minute traps

  • One Zone-IA is not Multi-AZ durable.
  • NAT for private→internet; VPC endpoint when "no internet / cheaper to S3/Dynamo".
  • CloudFront OAC (not legacy OAI) for private S3 origins in modern answers.
  • Activate cost allocation tags or chargeback won't show.
  • Untested backup ≠ DR plan.
