Further reading

The primary sources behind the guide — read these to go deeper. Each link is the canonical paper, spec, or explainer, with a one-line note on why it's worth your time. Every link opens externally.

These are the primary sources — the guide is the friendly version note

The links below are the original papers and specs: dense, authoritative, and sometimes heavy going. The guide's own pages are the plain-English translation. Read a guide page first to build intuition, then come here for the rigorous detail, the exact numbers, and the citations you can name in an interview.

01  Foundations & transformers

How the architecture works, why it scales, and the lineage that got us here.

Attention Is All You Need (2017)
The paper that introduced the transformer — the architecture under virtually every modern LLM. Start here.
RoFormer: Rotary Position Embedding (RoPE)
How today's models encode token position by rotating Q/K vectors — the trick that makes long context extend gracefully.
Language Models are Few-Shot Learners (GPT-3)
The paper that showed scale alone unlocks in-context learning — no fine-tuning needed to pick up new tasks.
Training Compute-Optimal LLMs (Chinchilla)
The scaling-laws result that reset how everyone balances model size against training tokens for a fixed compute budget.
The Illustrated Transformer (Jay Alammar)
The friendliest visual walkthrough of how a transformer actually computes attention — the best on-ramp if the original paper is too dense.

02  Prompting & RAG

Getting more out of a model with reasoning prompts and retrieval grounding.

Retrieval-Augmented Generation (RAG)
The original RAG paper — fetch relevant documents, condition generation on them. The blueprint for grounded answers.
ColBERT: Late Interaction over BERT
Keeps a vector per token and matches at query time — cross-encoder-like accuracy at near bi-encoder speed.
Chain-of-Thought Prompting
The paper that showed asking a model to "think step by step" sharply improves reasoning on hard problems.
From Local to Global: A GraphRAG Approach
Microsoft's writeup on building a knowledge graph from your corpus to answer broad "connect-the-dots" questions plain search misses.

03  Agents & tools

Putting a model in a loop where it can reason, call tools, and act.

ReAct: Synergizing Reasoning and Acting
The pattern behind most agents — interleave a "thought", a tool "action", and an "observation", then loop.
Model Context Protocol (modelcontextprotocol.io)
The open standard for connecting models to tools and data — "a USB-C port for AI." The home page for concepts and SDKs.
MCP Specification
The authoritative protocol spec — JSON-RPC messages, resources, prompts, and tools — when you need the exact wire details.
Toolformer: LMs Can Teach Themselves to Use Tools
An early, influential result showing a model can learn when and how to call APIs from self-supervised data.

04  Fine-tuning & alignment

Adapting a base model cheaply, and teaching it to be helpful and aligned.

LoRA: Low-Rank Adaptation
Freeze the big model, train tiny low-rank adapters instead — the foundation of parameter-efficient fine-tuning.
QLoRA: Efficient Finetuning of Quantized LLMs
LoRA on a 4-bit base model, so you can fine-tune very large models on a single consumer GPU.
InstructGPT: Training LMs to Follow Instructions (RLHF)
The paper behind the ChatGPT-era unlock — reward-model-based RLHF that turns a raw predictor into a helpful assistant.
Direct Preference Optimization (DPO)
Aligns a model straight from "preferred vs rejected" pairs — no separate reward model or RL loop required.
ORPO: Monolithic Preference Optimization
Folds instruction-tuning and preference learning into one stage, skipping the separate SFT pass entirely.

05  Inference & serving

Making models run fast and fit in memory once they're trained.

PagedAttention / vLLM
The paper behind vLLM — store the KV cache in OS-style pages to cut waste and serve far more concurrent requests.
Fast Inference via Speculative Decoding
A small draft model guesses several tokens ahead; the big model verifies them in one pass — same output, faster.
GPTQ: Accurate Post-Training Quantization
Quantize weights to 4 bits layer-by-layer while minimizing error — a big model on a smaller GPU.
AWQ: Activation-Aware Weight Quantization
Protects the few weights tied to important activations, keeping 4-bit quality high (the lineage behind GPTQ/AWQ/GGUF formats).

06  Evaluation & safety

Measuring whether a system works — and defending it against attack.

Ragas: Automated Evaluation of RAG
The framework that scores RAG on faithfulness and relevance using an LLM judge — no hand-labeled data needed.
OWASP Top 10 for LLM Applications
The industry-standard checklist of the biggest LLM security risks — prompt injection, data leakage, and more.
OpenTelemetry GenAI Semantic Conventions
The emerging standard for tracing LLM calls — prompts, tokens, latency, cost — so AI apps fit normal observability tooling.
Prompt injection series (Simon Willison)
The clearest running explanation of why prompt injection is hard to fix — essential reading before you ship anything agentic.

07  Diffusion & multimodal

How image, video, and cross-modal models are built.

Denoising Diffusion Probabilistic Models (DDPM)
The paper that made diffusion work for image generation — learn to turn noise into a picture one denoising step at a time.
High-Resolution Image Synthesis with Latent Diffusion (Stable Diffusion)
Run diffusion in a compressed latent space instead of raw pixels — the idea that made high-res generation cheap.
Scalable Diffusion Models with Transformers (DiT)
Swap the U-Net for a transformer backbone — the architecture behind many modern image and video generators.
Flow Matching for Generative Modeling
Trains models to follow a near-straight path from noise to data — high quality in far fewer steps than classic diffusion.
Rectified Flow (Flow Straight and Fast)
The companion idea to flow matching — straighten the trajectory so generation needs only a handful of steps.
CLIP: Learning Transferable Visual Models
Trains images and captions into one shared embedding space — the backbone of text-to-image and multimodal search.
Whisper: Robust Speech Recognition
OpenAI's weakly-supervised speech-to-text model — the reference point for modern transcription.
